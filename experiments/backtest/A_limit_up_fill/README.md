# 实验 A · 涨停可成交性（A_limit_up_fill）

状态：`scaffold`（纸面骨架，尚未接数据）。数据商 = **待定**。

## 1. 问题

同一信号，把「收盘价总能成交」改成「未复权涨跌停约束」后，收益和换手差多少？

## 2. 对照

| 腿 | 规则 |
|----|------|
| **A0** | 次日收盘价 100% 成交，忽略涨跌停 |
| **A1** | 一字涨停买入失败、一字跌停卖出失败；**卖出失败则继续持有至下一可卖日**；**买入失败则该信号空仓跳过** |
| **A1b（可选）** | 按当日成交量一小部分封顶；默认 `enabled: false`（见 `params.yaml`） |

## 3. 禁止事项

- 用**复权价**算涨跌停
- 把盘后固定价格当**无限量收盘成交**
- 给出具体买卖**标的结论**（不荐股）
- **实盘** / 券商 API / 开户
- 自行选定并登录数据商账号（数据商 = 待定；Raymond 点名之前不接聚宽 / 掘金 / 米筐）

## 4. 数据字段需求

| 字段 | 用途 |
|------|------|
| 未复权 OHLC | 成交与涨跌停判定底价 |
| 交易所前收盘 / 除权参考价 | 定涨跌停限制价 |
| 板块与 ST 标记 | 涨跌停幅度与样本过滤 |
| 上市日 | 剔除上市未满 60 日 |
| 退市整理起止 | 剔除退市整理窗 |
| 停牌 / 全日无成交标记 | 可成交性 |
| 成交量 | 仅 A1b 封顶用 |

## 5. 写死规则

1. **涨跌停**：未复权价 + 交易所前收盘（或除权参考价）定限制价；限制价**四舍五入到 0.01**。
2. **样本**：剔除上市未满 60 日；剔除退市整理窗。
3. **信号**：哑信号或固定换手规则；**禁止具体标的结论**。
4. **成本**：本实验可不计（留给实验 B）；股票 `t_plus_one: true`。
5. **输出**：`results/` 下净值差、计划换手 vs 实际换手、受阻买卖笔数、期末残余仓。
