# 实验 A · 涨停可成交性（A_limit_up_fill）

状态：`scaffold + fake dry-run`（假数据骨架对齐假设 A；**真数仍未接**）。数据商 = **聚宽**（已点名；假干跑用 FAKE；真数等本机 8765 鉴权，**不堵假跑迭代**）。

风控预检 = **有条件通过**；本版按缺口补齐 A1 宽规则、板块/ST 当日幅度、样本外切分占位。

## 1. 问题

同一信号，把「收盘价总能成交」改成「未复权涨跌停约束」后，收益和换手差多少？

## 2. 对照

| 腿 | 规则 |
|----|------|
| **A0** | 次日收盘价 100% 成交，忽略涨跌停 |
| **A1** | **触及涨停的买入记失败、触及跌停的卖出记失败**（与智库清单一致的更宽口径：含一字与非一字收盘涨跌停，**不限于一字板**）；卖出失败则继续持有至下一可卖日；买入失败则该信号空仓跳过 |
| **A1b（可选）** | 按当日成交量一小部分封顶；默认 `enabled: false`（见 `params.yaml`） |

### 为何 A1 不用「仅一字」

清单 2026-09-25 / 开跑前检查写的是「触及涨停的买入、触及跌停的卖出记未成交」。非一字但收盘仍停在板上的单，实盘同样经常排不到；若 A1 只罚一字，会把大量「收盘涨停仍记买入成功」留给曲线，诚信闸偏松。故 A1 = `limit_touch`（收盘价触及当日限制价即失败）。

## 3. 禁止事项

- 用**复权价**算涨跌停
- 把盘后固定价格当**无限量收盘成交**
- 给出具体买卖**标的结论**（不荐股）
- **实盘** / 券商 API / 开户
- 在真数鉴权未完成前登录聚宽拉全市场（本实验仅最小样本；禁实盘）
- 用 holdout **反调** A1 规则或换手参数

## 4. 数据字段需求

| 字段 | 用途 |
|------|------|
| 未复权 OHLC | 成交与涨跌停判定底价 |
| 交易所前收盘 / 除权参考价 | 定涨跌停限制价 |
| 板块与 ST 标记（含当日有效） | **按交易日×板块×风险警示取当时涨跌幅幅度** |
| 上市日 | 剔除上市未满 60 日 |
| 退市整理起止 | 剔除退市整理窗 |
| 停牌 / 全日无成交标记 | 可成交性 |
| 成交量 | 仅 A1b 封顶用 |

## 5. 写死规则

1. **涨跌停**：未复权价 + 交易所前收盘（或除权参考价）定限制价；限制价**四舍五入到 0.01**；**幅度按板块/ST 当日有效文本**（例：主板 10%；创业板/科创板 20%；主板 ST 在 2026-07-06 前 5%、此后 10%）。禁止用现行幅度铺满全历史。
2. **样本**：剔除上市未满 60 日；剔除退市整理窗。
3. **信号**：哑信号或固定换手规则；**禁止具体标的结论**。
4. **A1**：`limit_touch`——收盘触及涨停则买入失败，触及跌停则卖出失败（非仅一字）。
5. **成本**：本实验可不计（留给实验 B）；股票 `t_plus_one: true`。
6. **输出**：`results/` 下净值差、计划换手 vs 实际换手、受阻买卖笔数、期末残余仓、IS/holdout 分段对照。

## 6. 样本外切分（占位，未跑）

| 段 | 拟用区间 | 用途 |
|----|----------|------|

| holdout | `2024-01-01` .. `sample_end` | **只做一次**最终 A0/A1 对照表 |

`sample_end` 定稿前可微调边界日，但必须**事先写死再拉数**；禁止用 holdout 反调规则。
