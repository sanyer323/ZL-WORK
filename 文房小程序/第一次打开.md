# 第一次在本机预览（跟着点就行）

> 我无法远程操作您电脑上的微信开发者工具，请按下面步骤在本机点击。  
> 已开启 **本地预览模式**：不配云开发也能看界面、试充值和签到。

## 和 Cursor 云端协作（推荐）

我无法直接改您电脑上的文件，但可以改 GitHub 上的代码。您本机同步：

```powershell
cd 你的ZL-WORK目录
git pull origin cursor/wenfang-miniprogram-7818
```

然后在微信开发者工具里点 **编译**，即可看到最新改动。

若您用 Hermes 等工具在本机改过代码，请把改动 **commit + push** 到同一分支，或把改过的文件发我，避免两边不一致。

## 第二步：打开微信开发者工具

1. 启动 **微信开发者工具**
2. 微信扫码登录
3. 点击左侧 **「+」** 或 **「导入项目」**
4. 填写：
   - **目录**：选到 `文房小程序` 文件夹（里面有 `project.config.json`）
   - **AppID**：选 **测试号** 或 **使用测试号**（没有正式小程序也可以）
   - **项目名称**：文房书法
5. 点击 **导入**

## 第三步：在模拟器里看界面

导入成功后，中间会出现手机模拟器，应能看到：

- 顶部橙色导航 **「文房书法」**
- 首页余额、**充值** / **去签到** 按钮
- 顶部黄条：**本地预览模式**（说明当前是演示数据）

底部 Tab 可切换：**首页 · 签到 · 明细 · 我的**

## 第四步：试一遍流程（不用配云）

1. **充值**：首页 → 充值 → 选 1000 → 确认 → 余额增加  
2. **签到**：签到 Tab → 点击大圆钮 → 确认 → 扣 150 元  
3. **明细**：明细 Tab → 看充值/扣费记录  
4. **老板后台**：首页底部 **老板后台 →** → 看今日概况  

## 常见问题

**Q：导入时提示 AppID 无效？**  
→ 选「测试号」，不要填正式 AppID。

**Q：页面空白或报错？**  
→ 确认打开的是 `文房小程序` 文件夹，不是整个 `ZL-WORK` 根目录。  
→ 菜单 **工具 → 编译** 重新编译。  
→ 把报错截图发我。

**Q：想改成真实学员数据？**  
→ 先按 `README.md` 开通云开发，把 `config.js` 里 `CLOUD_ENV_ID` 改成你的环境 ID，预览模式会自动关闭。

**Q：想在真机上看？**  
→ 工具栏点 **预览**，用手机微信扫二维码（需登录同一微信开发者账号）。
