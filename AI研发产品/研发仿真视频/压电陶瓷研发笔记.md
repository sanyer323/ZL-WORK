## 1. 为什么用压电而不是线圈 I/P

| | 电磁线圈 I/P | FY301 压电挡板 |
|--|--|--|
| 稳态功耗 | 持续励磁电流 | 近似电容，稳态≈0 |
| 发热 | 明显 | 几乎无 |
| 回路电流 | 难做到 3.8 mA 级 | 适配两线 **3.8 mA** |
| 磨损 | 衔铁/气隙机械件 | 微米级弯曲，无摩擦副 |
| 响应 | 电感限制 | 电容充放电，快 |
| 驱动电压 | 低电压大电流 | **0–100 Vdc**，电流极小（FYCAL 电源限流约 **1 µA**） |

## 2. 物理层：逆压电效应

外加电场 E → 晶格极化方向伸长、垂直方向收缩 → **圆盘弯曲**（一端/边缘约束时形成挡板位移）。

电气模型：

```
i = C · dV/dt
```

电压恒定时 i≈0，因此整机可在最低 **3.8 mA** 回路供电下工作。

研发仿真脚本中的参考材料模型（非 SMAR 官方公开牌号，仅作仿真用）：PZT-5H 量级，`d33≈593 pC/N`；工程上压电片常粘在金属弹性基板上形成 **悬臂/双金属片式弯曲**，把微米应变放大为挡板位移。

## 3. FY301 里的压电组件（Piezo Base）

手册用语（FYCAL / FY301ME）：

| 名称 | 作用 |
|------|------|
| **Piezo Base（压电底座）** | 含压电片、盔帽、垫圈、弹簧、O 圈的整套换能组件 |
| **Metallic helmet（金属盔帽）** | 装压电片；可旋转调节高度 **h** |
| **Restriction（节流孔）** | 与喷嘴组成压力分流，向喷嘴供恒定小气流 |
| **Piezo vane / disk（压电盘/叶片）** | 先导级挡板；电压 → 挠曲 → 改变排气间隙 |

链路：

```
CPU → D/A → 隔离高压驱动（运行监控约 30–70 V）
        ↓
   压电盘弯曲（调节相对喷嘴/盔帽高度 h）
        ↓
   节流孔–喷嘴 压力分流
        ↓
   先导室压力 P_pilot
        ↓
   膜片力放大 → 滑阀 → OUT1 / OUT2
```

**控制电压（Control Voltage）**：当 `PV ≈ SP`（阀已到位）时加在压电上的电压。  
- 理想尽量接近 **50 Vdc**  
- 可接受 **30–70 Vdc**  
- **20–30 或 70–80 V**：仍能工作，应安排预防性维护/标定  
- **&lt;20 或 &gt;80 V**：**必须**拆机，用 FYCAL 标定压电底座  

现场检查：设定 10%–90% 任意点，待阀杆停稳后用手操器读压电电压。

块上标定定性（FYCAL 手册）：以 **50 V** 为中位调盔帽，使 OUT1≈OUT2 且尽量小；  
- V &gt; 50 V → OUT1 &gt; OUT2  
- V &lt; 50 V → OUT2 &gt; OUT1

## 4. FYCAL 标定判据（供气 20 psi）

### 4.1 以 FY301ME 维护节为准（产品手册）

装在 FYCAL 工装上单独标定压电底座：

| 步骤 | V_piezo | 先导室压力 P_pilot |
|------|---------|-------------------|
| 去迟滞 | 0 → 100 → 0 V | — |
| 调节点 | **50 V** | **5.8–6.2 psi**（旋盔帽调到此） |
| 验证 | **0 V** | **≤ 2 psi** |
| 验证 | **100 V** | **12–13 psi** |

**趋势（FY301ME）**：**电压↑ → 先导压↑**（挡板封堵喷嘴程度随电压增加）。

### 4.2 fycalme.pdf 中的另一组判据（工装手册）

| V_piezo | P_pilot |
|---------|---------|
| 50 V | ≈ 8 psi |
| 100 V | &lt; 3 psi |
| 0 V | &gt; 12 psi |

**趋势与 FY301ME 相反**。可能原因：接线极性约定、表计测点或版本差异。  
**本仓库仿真 / 讲解默认采用 FY301ME 表**；引用 fycalme 数值时必须注明来源与极性。

### 4.3 绝缘检查（fycalme）

| 方法 | 条件 | 不合格 |
|------|------|--------|
| 加压 | 100 Vdc，限流 1 µA | 压降 ≥ **2 V** → 换 piezo base |
| 兆欧表 | 100 V 档，盔帽针脚–壳体 | &lt; **50 MΩ** → 换 piezo base |

### 4.4 供电接线（FYCAL 给压电底座）

- **负极（黑）** → 金属盔帽中心 / 底座中心针  
- **正极（红）** → 未喷漆金属或固定螺丝  
- 电源能力：**0–100 Vdc，约 1 µA**

单独测合格但装回气路块仍无法标定 → 查 **膜片 / 滑阀**；单独测就不达标 → 清洗或更换压电元件。

## 5. 后级放大与闭环（简述）

先导流量/力太小 → 大/小膜片力平衡放大 → 滑阀大流量到 OUT1/OUT2。  
失电：OUT1→0，OUT2→供气压力。  
Hall + 磁铁（2–4 mm）→ PV → PID → 修正 V_piezo。
