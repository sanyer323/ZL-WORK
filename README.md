# ZL-WORK · 过程工业工程技术工作区

面向 **油气管道、智能站场、过程装置** 的流量测量与过程控制工程服务，并自研工程计算软件 **流衡 FlowSize**。

> 本仓库为内部/项目工作区总集，涵盖工程交付物、选型资料、CAD 出图脚本与自研软件源码。

---

## 业务定位

**过程工业流量测量 + 过程控制 + 工程计算工具**

| 板块 | 说明 |
|------|------|
| 差压流量测量 | ISO 5167 全系列一次元件选型、核算、出图（PRESO 族为主） |
| 调节阀与限流 | IEC 60534 调节阀选型；单级/多级限流孔板降压 |
| 变送器集成 | Rosemount 等差压/压力变送器型号分解与规格校核 |
| 自研软件 | [流衡 FlowSize](计算软件/) — Web 工程计算平台（MVP 0.1） |
| 研发培训 | SMAR FY301 压电定位器原理仿真与培训视频 |

**典型客户**：油气管道运营商、EPC 设计院、智能站场集成商、过程工业终端用户。

### 计算软件 · [流衡 FlowSize](计算软件/)

过程工业工程计算软件，覆盖调节阀 + 8 种差压/限流装置，标准可追溯、计算书可导出。

```bash
cd 计算软件
npm install
npm run dev      # 本地开发 http://localhost:5173
npm run build    # 生产构建
npm run preview  # 预览构建产物
```

详见 [计算软件/README.md](计算软件/README.md)。

### 画图 · 工程设计与 CAD

- **限流孔板**：PH02 濮阳-鹤壁天然气管道等项目的核算、结构图（DN50–DN200）
- **法兰对夹孔板**：FE-1002 生产机加装配图
- **工具链**：Python + ezdxf → DXF / PDF 计算书
- **标准**：ISO 5167、HG/T、SY/T 10043、API 521、Campbell 等

### 变送器选型

读规格书/数据单 → 型号分解 → 耐压/防爆/精度校核 → 输出选型文档。  
代表项目：西一线长兴站智能站场（Rosemount 3051CD）。

### AI 研发产品 · SMAR FY301

压电式智能阀门定位器的原理仿真、培训视频与互动工作台（电-气-机闭环：4–20 mA → 压电挡板 → 先导级 → 滑阀 → 霍尔反馈）。
