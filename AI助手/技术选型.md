# 技术选型

## 1. 软件栈

### 1.1 对话与 RAG

| 方案 | 优点 | 缺点 | 建议阶段 |
|------|------|------|----------|
| **公网 API**（OpenAI / 通义 / 豆包 / DeepSeek） | 上线快、效果好 | 数据出公网、按量付费 | P0–P1 首选 |
| **私有化**（Ollama + Qwen / Llama） | 数据不出场 | 运维、显卡成本 | P2 客户有要求时 |
| **RAG** LangChain / LlamaIndex / 自研轻量 | 生态成熟 | 依赖选型 | P1 起 |

**P0 推荐**：浏览器 Web Speech API（免费 STT）+ 可选 DeepSeek/通义 API（国内访问较稳）。

### 1.2 向量库

| 方案 | 适用 |
|------|------|
| **Chroma / FAISS 本地** | P0–P1 单节点 |
| **pgvector** | 已有 Postgres 时 |
| **Milvus / Zilliz Cloud** | P2 多站场 |

### 1.3 后端

| 方案 | 说明 |
|------|------|
| **FastAPI (Python)** | RAG、PDF 解析与现有 Python 脚本一致 |
| **Node + Hono** | 若前端全 TS，与 FlowSize 同栈 |

## 3. Pocket 硬件选型

| 方案 | 参考 | 单价感 | 说明 |
|------|------|--------|------|
| **A. XIAO ESP32S3 Sense** | Seeed | ~$15 | 带麦，需外接喇叭与电池 |
| **B. XIAO ESP32S3 + 定制 PCB** | 自研 | ¥80–150 BOM | EVT 后 |
| **C. reSpeaker Clip** | Seeed | ~$76 | 可穿戴录音，偏采集 |
| **D. 手机纯软** | — | ¥0 | P0 验证交互，无挂件壳 |

**挂件 v1 BOM 目标（EVT）**

| 件 | 规格 |
|----|------|
| MCU | ESP32-S3-WROOM，8MB Flash |
| 麦 | INMP441 或板载 |
| 喇叭 | 8Ω 0.5W 腔体喇叭 |
| 电池 | 3.7V 600 mAh |
| 充电 | USB-C + TP4056 |
| 连接 | BLE 5.0 + Wi-Fi |
| 壳 | 玩偶空腔 ≥ 60×40×25 mm |

**续航粗算**：待机 20 mA → ~30 h；对话 150 mA → ~4 h 累计。

## 6. 推荐组合（「一起」默认栈）

```
P0  Demo     : 静态 Web + Web Speech API + FAQ JSON + 可选 LLM API
P1  Station  : 平板 WebApp + FastAPI + Chroma + 通义/DeepSeek
P1  Pocket   : XIAO ESP32S3 + 手机 BLE 桥 + 同一 FastAPI
P2  边缘     : reComputer RK3588 或 Jetson Orin Nano + 本地 FAQ
P3  量产     : Fusion PCBA 挂件 + Station 工业平板 OEM
```
