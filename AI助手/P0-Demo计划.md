# P0 Demo 计划（2 周）

**目标**：用最小成本验证「同事是否愿意用语音问站场/仪表知识」—— Station 与 Pocket **共用同一 Web 对话界面**，Pocket 仅多一个「备忘」入口。

---

## 成功标准

- [ ] 5 位同事各完成 ≥3 次有效提问
- [ ] ≥70% 演示问题能命中 FAQ 或给出「文档未覆盖」拒答
- [ ] 收集 10 条「希望它能答」的真问题清单 → 输入 P1 RAG

## 演示脚本（5 分钟）

1. **Station**：按住说「PH02 两级孔板推荐孔径是多少？」→ 答 6.3 / 8.2 mm  
2. **Station**：「3051CD 推荐型号是什么？」→ 答型号串 + 订单号  
3. **Station**：「FY301 压电正常工作电压？」→ 30–70 V  
4. **Pocket**：「记一下：下周更新 FlowSize 限流孔板模块」→ 备忘列表出现  
5. **拒答**：「明天股票涨不涨？」→ 「我主要负责站场和仪表知识…」

## 环境

```bash
cd AI助手/p0-demo
python3 -m http.server 8765
# http://localhost:8765
# Chrome/Edge 推荐（Web Speech API）
```

可选 LLM：复制 `config.example.json` 为 `config.json`，填入 API Key（勿提交 git）。

---

## P0 → P1 门槛

| 条件 | 说明 |
|------|------|
| Go | ≥3 人认为「愿意日常用」且有明确 P1 试点岗位 |
| 调整 | 问题类型偏闲聊 → 收窄 FAQ + 改 prompt |
| No-Go | 无人使用或网络/语音完全不可用 → 先解决 Station 平板+文字 |
