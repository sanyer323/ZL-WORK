# FY301 TechMate · M0 原型

**AI 智能调试手操器** — 把 FY301 现场调试做成向导；培训视频**降级为按故障跳转的切片**，不再整片播放。

昨天现场霍尔被带电拔掉时，支援仍停在「看视频」。本原型把工程师培训版切成 5 段，霍尔段约 **2:35–3:19**。

## 运行

```bash
cd AI助手/fy301-techmate
python3 -m http.server 8766
```

Chrome/Edge 打开 **http://localhost:8766**

若本机有 `AI研发产品/研发仿真视频/out/FY301_工程师培训版.mp4`，「对应切片」页可直接跳播；没有 MP4 时仍显示该段字幕要点 + 仿真工作台链接。

## 试用场景

1. 点 **「⚡ 带电拔霍尔」** — 模拟昨天现场  
2. 切 **「逐步向导」** — 每步可「看切片」  
3. 切 **「对应切片」** — 只播霍尔段，不要从头放整部培训片  

## 版本规划

| 版本 | 能力 |
|------|------|
| **昨天** | 仅培训/仿真视频 |
| **M0（当前）** | 问答 + 向导 + 视频切片 |
| **M1** | 蓝牙 HART 读 PV/压电/Hall/报警码 |
| **M2** | Auto Setup / FYCAL 逐步联动 |
