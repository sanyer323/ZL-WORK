# 产品需求说明（PRD）

**版本**：0.1 草案  
**范围**：工厂助手（Station）+ 随身挂件（Pocket）+ 共享平台（Core）

---

## 1. 产品愿景

> 让站场和仪表知识「能听、能问、能答」——办公室用大屏，出门用挂件。

---

## 2. 用户与场景

### 2.1 工厂/站场助手（Station）

| 用户 | 场景 | 典型问题 |
|------|------|----------|
| 设计/工艺工程师 | 工位 | 「PH02 两级孔板孔径选用多少？」 |
| 现场仪表工 | 站场（安全区终端） | 「3051CD 量程 4 对应多少 MPa？」 |
| 项目经理 | 办公室 | 「WZDD-26-Z117 订单要几台？」 |
| 新员工 | 培训 | 「FY301 压电电压正常范围是多少？」 |

### 2.2 随身挂件（Pocket）

| 用户 | 场景 | 典型操作 |
|------|------|----------|
| 销售/商务 | 出差 | 「记：下周回访长兴站」 |
| 巡检工程师 | 路上 | 「今天 FO1101 在哪个站？」 |
| 管理层 | 日常 | 短问答、日程提醒 |

---

## 3. 共享平台（Core）— 两产品共用

| 模块 | Station | Pocket | 说明 |
|------|---------|--------|------|
| 语音识别 ASR | ✓ | ✓ | 按住说话优先；唤醒词二期 |
| 语音合成 TTS | ✓ | ✓ | 工厂可关外放仅字幕 |
| 对话引擎 LLM | ✓ | ✓ | 工具调用：查知识库 |
| 企业知识库 RAG | ✓ | ✓（子集） | 规程、计算书、选型、培训 |
| 身份与权限 | ✓ 必须 | ✓ 简化 | 工厂分角色；挂件绑个人 |
| 对话审计日志 | ✓ 必须 | ✓ 可选 | 谁问了什么 |
| 待办/备忘 | 二期 | ✓ v1 | Pocket 首发 |
| 第三方集成 | 钉钉/企微 | 手机蓝牙/APP | 分阶段 |

## 4. 功能清单

### 4.1 P0（2 周 · 内部验证）

- [ ] 浏览器 Demo：按住说话 → 文本 → 模拟/真实 LLM 回答
- [ ] 内置 **10 条** FAQ（来自 ZL-WORK 真实项目）
- [ ] 知识库文档清单（待 embedding 的 PDF/MD 列表）
- [ ] 产品 PRD + 架构 + 选型文档（本目录）

### 4.2 P1（6–8 周 · 单点试点）

**Station**

- [ ] 1 台工位设备（平板 + 定向麦 或 reTerminal 类）
- [ ] 按住说话，车间噪声下可用
- [ ] 登录（工号或简单 PIN）
- [ ] RAG：至少 50 份内部文档切片
- [ ] 回答带来源引用（文件名 + 页码/章节）

**Pocket**

- [ ] 1 套 EVT 硬件（ESP32-S3 + 麦 + 喇叭 + 500 mAh 电池）
- [ ] 短对话（≤30 s/轮），经手机 BLE 或 Wi-Fi 连云
- [ ] 一键备忘 → 写入列表（先本地/邮件，后接钉钉）

### 4.3 P2（3–6 月 · 可对外演示）

- [ ] 站场边缘盒：缓存 FAQ、弱网降级
- [ ] 权限：普通员工 / 工程师 / 管理员
- [ ] FlowSize 深链：「要算孔板吗？」→ 打开对应模块
- [ ] Pocket 玩偶外壳 EVT × 5 台内测
- [ ] 审计日志导出

### 4.4 P3（产品化）

- [ ] Station 批量部署 playbook
- [ ] Pocket 结构/电池/EMC 预研
- [ ] 可选：私有化 LLM 部署方案（客户站场无外网）

## 5. 明确不做（v1 排除）

| 不做 | 原因 |
|------|------|
| 双足行走 / Microduck 类机器人 | 成本高、维护难，非「全员助手」刚需 |
| 防爆区内置整机 | 终端放安全区，危险区只做音频中继 |
| 7×24 全时监听 | 隐私、合规、电量 |
| 替代 DCS/SCADA 操作 | 只读问答，不下发控制指令 |
| 通用闲聊为主 | 垂直知识助手定位，闲聊降级 |

---

## 6. 成功指标

| 阶段 | 指标 |
|------|------|
| P0 | ≥5 位同事愿意 weekly 使用 Demo |
| P1 Station | 试点 10 人，≥60% 问题能引用文档答对或正确拒答 |
| P1 Pocket | EVT 续航 ≥4 h 待机 / ≥30 min 累计对话 |
| P2 | 1 个客户场景完成演示（智能站场/设计岗） |
