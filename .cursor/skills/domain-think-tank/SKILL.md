# 分领域智库（丰富 AI 知识）

## 先认清：什么会变、什么不会

| 会变厚（您要的） | 不会 magically 变 |
|------------------|-------------------|
| Obsidian 笔记、Skills、仓库 kb | 底模权重不会因每天聊天被「练聪明」 |
| 领域坑、口径、清单、案例 | 同一模型裸聊、无知识库 → 一周后差不多 |

所以：**同一任务一周后再做，会不会完全不一样？**  
- **有智库沉淀** → 能明显更好（口径稳、少重复踩坑、更贴您）  
- **只靠聊天记忆** → 差不了太多  

目标：每个领域一个「罐」，Cursor 当研究员 + 入库员，Obsidian 当给人看的库，Skill 当给 AI 的短规矩。

## 领域罐结构（举例）

在 Obsidian 与/或 `~\.cursor\skills\` / 仓库 kb 中按领域分罐，例如：

```text
智库/
  金融股票/
  工业产品-定位器/
  视频制作/
  编剧/
```

每罐建议固定几类笔记（增量写，不整篇重写）：

1. `口径.md` — 主人怎么看这个领域（人性、禁止装逼等）  
2. `事实与坑.md` — 可复用结论（带日期）  
3. `清单与配方.md` — 怎么做某类任务  
4. `案例.md` — 做过的任务摘要 + 链接  

稳定、短、可执行的 → 再提炼进对应 **Skill**（如 `owner-prefs`、`positioner-rd`、某领域 skill）。

## 每天/每周怎么养智库（推荐）

### A. 人工轻量（立刻能用）

对某个领域对话说：

```text
按 domain-think-tank：今天只做「金融股票」学习入库。
主题：……；中短线+人性视角；最后给出：可写进口径/事实/清单的条目（增量），并问我是否写入 Skill。
```

或任务结束时：

```text
本次可沉淀什么？按领域写入 Obsidian 提纲 + 是否更新 Skill。
```

### B. 定时自动（Cursor Automation）

建 Automation：每天/每周触发 Cloud Agent，prompt 示例：

```text
领域：金融股票（或轮换领域）。
按 owner-prefs + domain-think-tank：网上检索本周要点，
只保留可复用结论；增量写入仓库 docs/kb/<领域>/ 条目；
禁止整篇重写；不给投资建议口吻，中短线博弈视角。
```

Automation ≈ 定时喂料；**不是** Hermes 那种自己进化交易模型。

### C. 和「两版+主模型」的关系

- 养智库、学概念：单模型即可  
- 真正改电路/固件/上线：仍用 dual-model-watch  

## 主人用法（默认）

1. **开领域会话**（或同会话声明领域）  
2. **学 / 做任务**  
3. **强制收尾入库**（事实进 kb/Obsidian，规矩进 Skill）  
4. **下次同领域先读罐再开干**

跨任务看：时间越久，罐越厚 → 同题完成度应更高；这就是「每个领域的智库」。
