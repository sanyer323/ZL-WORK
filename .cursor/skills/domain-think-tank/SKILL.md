# 分领域智库（丰富 AI 知识）

## 先认清：什么会变、什么不会

| 会变厚（您要的） | 不会 magically 变 |
|------------------|-------------------|
| Obsidian 笔记、Skills、仓库 kb | 底模权重不会因每天聊天被「练聪明」 |
| 领域坑、口径、清单、案例 | 同一模型裸聊、无知识库 → 一周后差不多 |

所以：**同一任务一周后再做，会不会完全不一样？**  
- **有智库沉淀** → 能明显更好（口径稳、少重复踩坑、更贴您）  
- **只靠聊天记忆** → 差不了太多  

目标：每个领域一个「罐」，Cursor 当研究员 + 入库员，Obsidian 当给人看的库，Skill 当给 AI 的短规矩。

## 领域罐结构（举例）

在 Obsidian 与/或 `~\.cursor\skills\` / 仓库 kb 中按领域分罐，例如：

```text
智库/
  金融股票/
  工业产品-定位器/
  视频制作/
  编剧/
```

每罐建议固定几类笔记（增量写，不整篇重写）：

1. `口径.md` — 主人怎么看这个领域（人性、禁止装逼等）  
2. `事实与坑.md` — 可复用结论（带日期）  
3. `清单与配方.md` — 怎么做某类任务  
4. `案例.md` — 做过的任务摘要 + 链接  

金融罐额外目标（2026-09-19）：为**量化操作打基础**——喂养优先数据/因子/回测诚信/风控/执行鸿沟；人性与拥挤写成可编码理解，不写成荐股。

稳定、短、可执行的 → 再提炼进对应 **Skill**（如 `owner-prefs`、`positioner-rd`、某领域 skill）。

## 每天/每周怎么养智库（推荐）

### 默认：持续喂养（主人不用说「今天养」）

AI 在**打开的对话里**不会 24 小时自己上网；要持续养，用 **Cursor Automation 定时跑**（人不累也得靠闹钟触发）。

- 现成文案：`AI研发产品/docs/kb/automation-智库持续喂养.md`
- 操作：Cursor → Automations（或 `/automate`）→ 每天触发 → 贴上该文案 → 绑仓库
- 领域按星期轮换；入库到仓库根目录 **`智库/<领域>/`**（Obsidian 直接打开此文件夹），规矩增量进 Skills
- 本机安装 Obsidian：见 `智库/本机安装说明.md`

主人日常**不必**再说「今天养××」；只有想加餐某个主题时再说一声即可。

### A. 加餐 / 任务收尾（可选）

```text
加餐：金融股票，主题……
```

或任务结束：

```text
本次可沉淀什么？入库。
```

### B. 和「两版+主模型」的关系

- 养智库、学概念：单模型 + Automation 即可  
- 真正改电路/固件/上线：仍用 dual-model-watch  

## 主人用法（默认）

1. **Automation 持续喂罐**（主路径，见 kb 里 automation 文案）  
2. 开领域会话做事时仍可顺手入库  
3. 想加餐再点名主题；**不必每天说「今天养」**  
4. 下次同领域先读罐再开干  

跨任务看：时间越久，罐越厚 → 同题完成度应更高；这就是「每个领域的智库」。
