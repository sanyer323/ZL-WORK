## 重要任务：两版 + 主模型取舍（强制）

**经验**：FY301 电路板——两模型各改一版，再问主模型；主模型能说清为啥改、怎么取舍。  
主人可不懂技术；要的是这种万无一失的综合，**不是**两边机械互辩。

开场：

```text
按 positioner-rd / dual-model-watch：两版实现，主模型综合取舍并定稿。
```

细则见 `dual-model-watch` Skill 与同目录 `dual-model-watch.md`。

## 标准分层（2026-09-19）

- 阀本体：GB/T 4213-2024（2025-07-01 实施，代替 2008《气动调节阀》）
- 定位器性能：GB/T 22137.1-2008、GB/T 22137.2-2018（2025-05-30 复审继续有效）
- 安装接口：直行程 IEC 60534-6-1:1997 = GB/T 17213.6-2005；角行程 IEC 60534-6-2:2000
- 禁止把阀标准写成定位器合格证。

## 选型分层（2026-09-19 晚）

- **防爆**：设备证 GB/T 3836.1/2/4-2021 ≠ 安装规范 **GB 3836.15-2024**（2025-08-01 强制，代替 2017）；**IP（GB/T 4208）≠ Ex**；隔爆 d ≠ 本安 i（本安是回路）。
- **故障显示**：NE43 = 模拟电流故障带；NE107 = 数字四态。不要把 21 mA 写成维护请求。写「符合 NE43」须对厂家选项和 AI 卡量程。
- **故障位**：失气弹簧位由工艺危险定；定位器保位/泄气另问。双作用无弹簧没有天然失气开关。
- **差压变送器**：量程码 ≠ 静压 ≠ 过压。细则在 `智库/工业产品-定位器/`，不新建空 skill。

## HART / 台架默认（2026-09-22）
- FY301 的 4–20 mA 是**控制器给定（灌入）**，阀位是霍尔反馈；不要按变送器「电流=测量 PV」来接、来讲、来写固件。
- 地址 **0** 才走模拟定位（出厂默认）；地址 **1–15** / 屏显 `MD` = 电流钉在约 4 mA，模拟给定失效。先改地址，再查气/电。
- 手册图 1.12「multidrop (split ranges)」是**最多两台串联分程**，不是 HART 并联多点。分程按 **22 V / 1100 Ω** 算 AO；单台 **11 V / 550 Ω**，最低 **3.8 mA**。
- FY301 ≠ FY302/FY303（后两者总线供电约 12 mA）。无 DD 不猜 Cmd 48 / Device Specific；命令表不整表进 Skill。
## 仿真视频成片（2026-09-23）

- 默认产出：**独立 UTF-8 SRT** + 软字幕轨；烧录只作对方播不了字幕轨时的交付件。
- 编码默认：MP4 / H.264 / yuv420p / AAC / **恒定帧率** / **SDR BT.709**。源是 20 fps 就别强升 30。

## 选型分层（2026-09-26）
- 防爆：设备证（GB/T 3836.1/2/4）≠ 安装（GB 3836.15-2024）≠ 检查维护（GB 3836.16-2024）；本安还要看系统（GB/T 3836.18-2024）
- 隔爆 ≠ 本安；IP（GB/T 4208）≠ Ex
- 失气弹簧位 ≠ 丢信号位（IEC 60534-7 第 29/30 栏）；单作用不要承诺失气保位
- NE43 故障电流 ≠ NE107 诊断四态
- 差压量程 ≠ 静压 ≠ 过压；IEC 62828-2:2026 是试验程序不是选型手册
## 选型分层（2026-10-03）
- 调节阀口径（GB/T 17213.2-2017 = IEC 60534-2-1:2011）≠ 测量孔板（GB/T 2624.2-2006 仍采 ISO 5167-2:2003）≠ 泄压减压（SY/T 10043-2002 / API STD 521:2020）
- 泄漏等级：国标 GB/T 17213.4-2015 = IEC 60534-4:2006；IEC 已到 2021。例行试验 ≠ 现场关严
- 细则在 `智库/工业产品-定位器/`；不新建空 skill，不写 FY301 命令表
## 仿真视频成片（2026-09-27）
- 研发仿真 ≠ 营销片；原理讲解与排故口吻分开出片
- 本仓库默认 **20 fps**，按源上传，不升 30
- 成片：MP4 + H.264 + AAC；Closed GOP；Fast Start；无 Edit Lists；SDR 用 BT.709
- 软字幕优先；`.srt` 用 UTF-8、不要样式。网页播放另出 WebVTT
- 响度用 BS.1770 量；广播交片按 R128 **−23 LUFS / −1 dBTP**。没有官方页的平台靶不写
## 仿真视频成片（2026-09-30）
- 本仓库 TTS/静音轨默认 **16 kHz**；外发前重采样到 **48 kHz**
- 源是 20 fps 时，外发 Closed GOP = **10 帧**（半帧率）；成片加 Fast Start（`-movflags +faststart`）
- 响度用 ffmpeg `ebur128` 看 `I` / 真峰值，不要用峰值表或 `loudnorm` 默认值冒充规范。中国数字电视 GY/T 282：**−24 LKFS / −2 dBTP**；欧广电 R128：**−23 LUFS / −1 dBTP**。对内培训不必套电视台靶

## HART / 台架默认（2026-09-29）
- 4–20 mA 进 FY301 = **Auto 的阀位给定**，不是阀位变送；阀位看霍尔 / LCD / HART
- 分程串联（550 Ω × 2 = 1100 Ω，**22 V**）≠ HART 多点（地址 1–15，LCD **MD**，电流钉约 4 mA）。FY301ME 图 1.12 标题会混写，以电流是否还在 4–20 分段为准
- FY301 = HART；FY302 = FF；FY303 = PA；FY400 是另一代。不混 DD、不混通讯板
- 无 DD / 无 FY301 命令规范手册，不猜厂家命令；**禁止把命令表塞进本 Skill**（`hart-fy301.md` 仍不空建）
- 现场「给定变了阀不动」：先看 Auto/Man 与是否 MD，再查气源
