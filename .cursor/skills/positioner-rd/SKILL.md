## 选型分层（2026-09-19 晚）

## HART / 台架默认（2026-09-22）
- FY301 的 4–20 mA 是**控制器给定（灌入）**，阀位是霍尔反馈；不要按变送器「电流=测量 PV」来接、来讲、来写固件。
- 地址 **0** 才走模拟定位（出厂默认）；地址 **1–15** / 屏显 `MD` = 电流钉在约 4 mA，模拟给定失效。先改地址，再查气/电。
- 手册图 1.12「multidrop (split ranges)」是**最多两台串联分程**，不是 HART 并联多点。分程按 **22 V / 1100 Ω** 算 AO；单台 **11 V / 550 Ω**，最低 **3.8 mA**。
- FY301 ≠ FY302/FY303（后两者总线供电约 12 mA）。无 DD 不猜 Cmd 48 / Device Specific；命令表不整表进 Skill。

## HART / 台架默认（2026-09-29）
- 4–20 mA 进 FY301 = **Auto 的阀位给定**，不是阀位变送；阀位看霍尔 / LCD / HART
- 分程串联（550 Ω × 2 = 1100 Ω，**22 V**）≠ HART 多点（地址 1–15，LCD **MD**，电流钉约 4 mA）。FY301ME 图 1.12 标题会混写，以电流是否还在 4–20 分段为准
- FY301 = HART；FY302 = FF；FY303 = PA；FY400 是另一代。不混 DD、不混通讯板
- 无 DD / 无 FY301 命令规范手册，不猜厂家命令；**禁止把命令表塞进本 Skill**（`hart-fy301.md` 仍不空建）
- 现场「给定变了阀不动」：先看 Auto/Man 与是否 MD，再查气源
## HART / 台架默认（2026-10-06）
- **给定环 ≠ 阀位回讯环**：标准 4–20 mA 只灌入 Auto 给定；模拟回讯须订 **K2**（开集电极）。K1=诊断压力，不是回讯。
- **断 4–20 mA**：OUT1→0、OUT2→气源。单作用接 OUT1、堵 OUT2。这不是弹簧失气位，也不是软件保位。
- **分程三层**：单台 LOPOS/UPPOS（阻抗仍 550 Ω）≠ 两台串联（1100 Ω / 22 V）≠ 地址 1–15 钉约 4 mA。FY301ME 无 Loop Current Mode，不要按 FieldComm「分程也改非 0 地址」去保模拟给定。
- 细则在 `智库/工业产品-定位器/`；命令表仍不进 Skill，不空建 `hart-fy301.md`
## HART / 台架默认（2026-10-13）
- **Auto Setup 报错先拆三层**：`HALL`＝扁平电缆/霍尔传感器；`FAIL MOVE`＝没气或滑阀卡住；`MGNT`＝磁铁没装或中位箭头没对。60–80% 停住才改 Kp。
- **磁铁**：中位箭头对箭头，外表面到定位器 **2–4 mm**；换磁铁/挪位置要重做 Auto Setup。半行程霍尔为零场，两端电压由自校准测，不手填。
- **远程霍尔 ≠ K2**：高温/振动选件，电缆最长 **20 m**，工作到 **105 °C**；K2 才是模拟阀位回讯。不要把 FY303/FY400 的 PST 套到 FY301。
- 细则在 `智库/工业产品-定位器/`；命令表仍不进 Skill，不空建 `hart-fy301.md`
## HART / 台架默认（2026-10-20）
- **TSO ≠ Auto Setup 0% ≠ 泄漏等级**：TSO/TSO D 是软件关严带（手册例 5% / 1%），会吃掉给定前几个百分点；行程两端仍走 Auto Setup。
- **W1 ≠ W2**：W1 ON 才允许本地磁棒改编程树（要有 LCD；Z 浏览 / S 选中）；W2 DOWN = 写保护。组态时放开写，改完再保护。电流 trim ≠ 行程标定。
- **K1 读气压**：可选板读气源 / OUT1 / OUT2，供 HART 诊断，不进霍尔闭环，也不是 K2 回讯。
- 细则在 `智库/工业产品-定位器/`；命令表仍不进 Skill，不空建 `hart-fy301.md`
## HART / 台架默认（2026-10-27）
- **TIME ≠ Kp ≠ TR**：TIME 是给定变化时间（1–60 s），不是比例增益，也不是阀组件行程时间。快阀冲过头先加大 TIME，不要先砸 Kp。振荡看 Kp / TR。
- **本地 CHAR 是子集**：磁棒只有 Lin / EP50 / HY50 / Tab；UNALTERED 和 1:25 / 1:33 只在手操器。阀芯已是等百分比不要再选 EP50。

## 选型分层（2026-10-25）
- **气源总管 ≠ 第 28 栏仪表气源 ≠ 过滤减压阀**：总管是厂里来的气；第 28 栏是定位器/增压器真正吃到的表压；中间通常要过滤减压阀。活塞缸直吃高厂用气时手册才说常常可以不要减压阀
- **过滤减压阀 ≠ 增压器**：减压阀降压+过滤；volume booster 补气量、不抬压力。67C 类内置泄放只管微量内漏，不是过压保护
- 细则在 `智库/工业产品-定位器/`；不写命令表
