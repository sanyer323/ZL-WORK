# 过程工业流量测量与过程控制 · 业务一页纸

**定位**：过程工业流量测量 + 过程控制 + 工程计算工具  
**服务对象**：油气管道运营商 · EPC 设计院 · 智能站场集成商 · 过程工业终端用户

---

## 我们能做什么

| 服务 | 内容 | 依据/品牌 |
|------|------|-----------|
| **差压流量一次元件** | 选型、核算、计算书、结构出图 | ISO 5167 全系列；PRESO 文丘里/楔形/V 锥/均速管等 |
| **限流孔板 RO** | 单级/多级降压、放空核算、CAD 出图 | HG/T、SY/T 10043、API 521、Campbell |
| **调节阀选型** | Cv/Kv、阻塞流、气蚀闪蒸 | IEC 60534（制造商中立） |
| **变送器集成** | 差压/压力变送器型号分解与规格校核 | Rosemount 等 |
| **工程计算软件** | 流衡 FlowSize — 标准可追溯、计算书可导出 | 自研 Web 平台 |
| **培训与仿真** | 智能定位器等产品的原理讲解与互动仿真 | SMAR FY301 等 |

---

## 核心产品线（差压计量）

- 标准孔板 · 调整型/平衡孔板  
- 文丘里管 / 喷嘴 · 楔形流量计 · V 锥 · 均速管（椭圆巴）  
- 限流孔板（放空、降压限流）

---

## 代表业绩（节选）

- **濮阳-鹤壁天然气输气管道**：15 台二级限流孔板核算与结构出图（CL600，DN50–DN200）  
- **西一线长兴站智能站场**：差压变送器选型与型号分解（3051CD）  
- **过程装置流量计量**：法兰对夹孔板生产级机加装配图交付

## 自研产品 · 流衡 FlowSize

面向过程工业的 **调节阀 + 差压节流装置** 工程计算（CONVAL 类能力方向）。

- 9 个计算模块 · 约百种工质库 · 计算书导出  
- Web 优先，同一引擎可扩展桌面端  
- 版本：MVP 0.1

本地体验：`cd 计算软件 && npm install && npm run dev`
