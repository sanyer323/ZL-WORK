# 业务 1：Token / API 转售 — 执行方案

> 目标：用百度销售给的主流模型折扣价，经香港公司加价卖给境外客户，先见到美元现金流。  
> 不做：灰 Key、共享账号、无限包月、先砸钱自建大平台。

---

## 0. 这门生意一句话

```
百度折扣 Token（进） → 香港公司加价（出） → 客户按量付 USD
```

你卖的是**可对账的调用额度**，不是百度后台账号。

---

## 1. 执行总览（按关卡走，不过关不往下砸钱）

| 关卡 | 时间 | 你要完成什么 | 过关标准 |
|------|------|--------------|----------|
| A. 授权确认 | 第 1 周 | 百度销售书面答复 | 港司能用、允许转售第三方、结算方式清楚 |
| B. 算清账 | 第 1 周 | 填报价表 | 加价后毛利仍可接受（建议贡献利润 ≥ 25%） |
| C. 最小交付 | 第 2–3 周 | 能给客户 Key + 账单 | 客户能调通模型，你能看到用量 |
| D. 收款闭环 | 第 3–4 周 | 港司收第一笔 USD | 钱进账、能对应到客户用量 |
| E. 种子放量 | 第 2 个月 | 3–5 个付费客户 | 月复购/续充出现 |

任一关卡不过：**停，先解决，不扩大获客。**

## 2. 关卡 A：先问百度销售（本周就发）

把下面整段复制发微信/邮件，要求**书面回复**（聊天记录截图归档也行）：

---

你好，我们准备用香港公司面向境外客户提供 API 调用服务，需要先书面确认几件事，方便我们合规推进：

1. **主体**：香港公司能否直接开户/签约结算？需要境内主体配合吗？结算币种是人民币还是美元/港币？发票怎么开？
2. **转售**：我们拿到的模型 Token 折扣（DeepSeek / GPT 类等），是否允许加价转售给**境外第三方客户**？还是仅限自用？
3. **客户落户**：客户用量能否开在我们主账号下的**子账号/项目**里，由我们统一向百度结算、再向客户收款？
4. **模型清单与价格**：目前可给的折扣模型名单、官方价、给我们的结算价（按百万 tokens 或你们的计费单位），有无锁定期/调价通知期？
5. **合规**：面向海外时，内容安全、数据跨境有没有必须遵守的书面要求？
6. **支持**：探索期能否给测试额度，方便我们接 1–2 个种子客户验证？

请尽量逐条回复，我们据此决定是否启动对外销售。谢谢。

| 百度态度 | 你怎么做 |
|----------|----------|
| 明确允许转售 + 可子账号 | **绿灯**，进入关卡 B/C |

## 3. 关卡 B：算账与定价（填表即可）

### 3.1 定价公式（先用这个，别想复杂）

```
卖价 = 百度结算成本 × 1.5～1.8
```

- 早期用 **1.6～1.7**：既显得便宜，又留支付和客服余量  
- 对外展示两列：**参考官网价** vs **你们价**（客户一眼觉得划算）

### 3.2 必算的一张表（每个模型一行）

| 模型 | 百度结算价（$/1M tokens） | 你的卖价 | 倍率 | 支付费约 3% | 粗毛利 | 是否上架 |
|------|---------------------------|----------|------|-------------|--------|----------|
| DeepSeek-Chat | （填） | （填） | | | | 先上 |
| 通义 / GPT类等 | （填） | （填） | | | | 先上 3～5 个 |

**过关**：至少一个主力模型，扣掉约 3% 支付后，仍有可接受差价。  
若倍率要到 2.5 才有钱赚 → 说明进价没优势或售价没人买，先别做。

### 3.3 套餐怎么卖（建议极简）

先不要复杂套餐，只做：

1. **预充值**：客户付 $100 / $500 / $1000 到港司，你给余额  
2. **按量扣费**：有调用就扣余额  
3. **余额不足停服**：避免欠费追款  

后期再做月结企业客户。

## 4. 关卡 C：最小交付（两周内能卖）

原则：**先人工也能跑通，再自动化。**

### 4.1 你必须具备的 4 样东西

1. **给客户的调用方式**  
   - 最好：一个 Base URL + API Key（OpenAI 兼容最省事）  
   - 过渡期：你用百度 Key 在后台代调也行，但要用**分客户的用量记录**（表格也行）

2. **用量台账**（Excel/飞书表即可起步）  
   - 客户名 / Key / 日期 / 模型 / tokens / 扣费 USD / 余额  

3. **英文一页说明**（半页也行）  
   - Base URL、如何拿 Key、模型名、价格、充值方式、支持邮箱  

4. **香港公司收款账户**  
   - 公司收款码 / 银行账户 / Stripe（有最好，没有就先公对公或合规收款渠道）

### 4.2 技术最小方案（按你精力选）

| 方案 | 适合 | 做法 |
|------|------|------|
| **C0 全人工** | 第 1～3 个客户 | 你代开通、每周对账、表格扣费 |
| **C1 One API / 同类网关** | 准备接更多客户 | 一台香港/新加坡轻量服务器挂网关，背后接百度折扣通道 |
| **C2 百度侧子账号** | 销售允许子客户 | 少自建，尽量用百度组织/项目管理用量 |

建议顺序：**A 绿灯后先 C0 接 1 个付费客户 → 再上 C1。**  
不要授权没确认就先买服务器、先开发。

### 4.3 客户调用示例（你文档里就放这个）

```text
Base URL: https://api.你的域名.com/v1
API Key: sk-客户自己的key
```

兼容 OpenAI SDK：改 `base_url` 和 `api_key` 即可。

## 5. 关卡 D：香港公司怎么盈利闭环

### 5.1 资金流（钉死）

```
客户付 USD → 香港公司账户
香港公司按折扣向百度结算（按合同币种）
差额 = 你的毛利
```

注意：

- 客户合同/账单抬头用**香港公司**  
- 百度结算主体按销售确认的主体走（可能是港司，也可能要境内配合）  
- 留一份：客户充值记录 ↔ 百度账单 ↔ 银行流水 的对应关系（将来投资人/审计都看这个）

### 5.2 第一单怎么做成（脚本）

1. 找 1 个熟人开发者或小团队  
2. 收一笔小额预充（如 $50–$100）试水  
3. 开通 Key，发英文调用说明  
4. 让对方跑通一次 `chat/completions`  
5. 你在台账记下用量并扣费  
6. 一周后问：稳不稳、会不会续充  

**过关 = 第一笔钱进港司账户，且能对上一次真实调用。**

## 6. 关卡 E：找谁买、怎么卖

### 6.1 第一批客户画像（别好高骛远）

- 开发者社群：给 Base URL + 价目 + 充值方式  
- 不要一上来投大量广告；先服务好 5 个付费用户

### 6.3 话术要点（对外怎么说）

- 说：Hong Kong entity billing · pay-as-you-go · OpenAI-compatible API  
- 说：access to leading Chinese models at competitive rates  
- **不要说**：国内黄牛、共享官方账号、保证比全世界都便宜

## 8. 风险与红线（写进你自己的纪律）

1. **无书面转售许可，不对外卖**  
2. **不把百度主账号密码给客户**  
3. **不做无限用月费**（极易亏穿）  
4. **单客户设配额上限**，防盗刷  
5. **预充值优先**，月结只给信得过的客户  
6. 某个模型被官方渠道冲击降价 → 立刻调价或主推别的模型，不硬扛
