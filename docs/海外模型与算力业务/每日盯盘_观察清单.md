# 每日盯盘 · 观察清单（按本公司业务裁剪）

## 公司现状（盯盘必须以这为准）

- 供给：百度销售可批的主流模型 Token 官方折扣  
- 主体：香港公司，对外 USD 收款  
- 业务 1：Token/API 转售（主线）  
- 渠道策略：优先找中转站/小平台当经销商（upstream），自己获客为辅  
- 业务 2：后置（AI+外贸 / AI+3D 只选一个），每日盯盘暂不主报  
- 不做：灰产号池、日抛号、未授权转售

## 盯盘目标（只报「对我们决策有用」的）

1. **定价参考**：上表白名单模型在海外公开平台卖多少 → 我们批发/零售价怎么定  
2. **需求信号**：白名单里谁更热 → 优先跟百度要哪些折扣、优先推给中转站  
3. **渠道机会**：哪些聚合/中转在推上述模型、缺稳定上游 → 可联系名单  
4. **竞争威胁**：官方直连降价/上架 → 我们差价还在不在  
5. **行动建议**：今天该不该调价、该不该联系某类站长、该不该向百度要某模型额度  

**不报**：白名单以外的长评测、B300 持卡出租、灰产号池教程。

## 优先观察对象

### A. 出海公开平台（有公开数据，每日必看）

| 平台 | 看什么 | 对我们的用处 |
|------|--------|--------------|
| OpenRouter | 中国模型榜、定价、$/M tokens、最近趋势 | 海外零售锚价；判断 DeepSeek 等是否仍好卖 |
| 其他可公开查到的聚合价目（如有） | 同模型价差 | 我们给中转站的批发价是否有空间 |

### B. 中转站生态（公开页面能看的；无私有成交量）

| 信号 | 看什么 | 对我们的用处 |
|------|--------|--------------|
| 测评站/榜单（如视频提到的众测类） | 在线率、折扣、是否掺水口碑 | 筛选「值得谈 upstream」的站 |
| 站长公开价目 | 国产模型分组倍率、是否主推 | 我们的进货能否让对方有赚头 |
| 新站/倒闭传闻 | 稳定性 | 避免把量压在一家 |

> 说明：中转站**真实成交额**一般不公开。每日报告用「公开定价 + 上架情况 + 口碑信号」代替「交易额」，除非你之后提供某站后台只读权限。

### C. 上游与政策（隔日或有新闻时）

| 来源 | 看什么 |
|------|--------|
| 百度智能云/千帆公开价格与国际站动态 | 官价变动是否挤压你的折扣优势 |
| 模型厂商公开调价（DeepSeek 等） | 成本端是否变化 |

## 每日报告固定结构（自动任务必须按此输出）

1. **一句话结论**（今天对我们业务 1 意味着什么）  
2. **价格表**：重点模型在 OpenRouter（及能查到的中转公开价）vs 粗算「我们若按成本×1.6 出售」是否仍有空间（无真实进价则标「待填百度结算价」）  
3. **需求热度**：今日/近几日公开榜上中国模型变化  
4. **渠道线索**：1～3 个值得接触的平台/站类型（附联系或页面线索）  
5. **风险**：官方向上架、价差收窄、掺水传闻影响信任  
6. **今日建议动作**（最多 3 条，可执行）
