# 工业自动化业务说明（内部备用）

本文按当事人自述整理，供后续写公司背景、业务说明或续签材料时对照。不是营销稿，也不改业务事实。

## 1. 做什么、卖给谁

公司做工业自动化相关贸易与配套，终端客户是石化、化工等有流程控制需求的企业。生意围着这些终端转，不是面向散户零售。

链条上的角色通常包括：

- 生产厂
- 国际品牌的项目代理商
- 大型总包商（EPC）
- 终端用户（石化 / 化工流程装置）

成交形态以**项目制**为主，同时有**零星、非项目的日常采购**（备件、补货、小额加购）。

## 2. 行业里内地怎么做单（本行业惯例）

内地做这一行，常见是贸易商过单，而不是自建大仓库：

- 签合同、采购、开票、收款、指令发货，都在国内完成
- **货物不进本公司仓库**，由供货方按指令发给客户或指定地点
- 靠负责人维护客户关系和项目节点，而不是靠店面零售

这是真实买卖：有合同、有票、有款、有发货指令，只是货权与仓储不一定经过自己的仓。

## 3. 香港公司怎么做（同一套贸易，合同性质不同）

香港公司做的是同一条生意、同一类客户和项目，不是另做一套「只开票」的空转。

差别在合同和结算：

- 采购、销售签的是**进出口合同**
- 开票、收款在**香港公司**
- 货物按指令进入**保税区 / 保税仓**，有**出口报关单和进口报关单**
- 公司仍以过单为主，货不进香港办公室，也不要求货进自有仓

货权、报关、合同、银行收款应对得上。这是有报关的保税进出，不是「货在内地工厂之间直接调拨、只把合同做成进出口、无报关」的假走单。

香港作为贸易港：香港公司是签约和结算主体，留合理毛利（利润率不低，不是通道费过账）。采购 / 销售对象以无关联第三方为主。

## 4. 为什么有时要国内公司中转

项目制 + 日常零星采购并存时，到货批量和出货节奏经常不一致。例如：项目或备货需要一次进 10，当下只出 1，其余 9 个要在后续项目或日常采购中慢慢消化。

若全部压在香港侧保税仓（当事人所称玉田等相关保税仓储），仓储费用高。做法是：

- **国内公司做中转**：按实际需要进口 / 接货一批（如 10）
- 先卖出当下要的部分（如 1）
- 余量（如 9）由国内公司持有并分批销售

目的是**降低保税仓储成本、匹配项目与零星出货节奏**，不是把无真实买卖的货在关联公司之间空转。国内公司中转的那一段，仍应对应真实后续销售。

## 5. 两条主体怎么分工（一句话）

| | 香港公司 | 国内公司 |
|---|---|---|
| 角色 | 进出口签约、开票、收款、利润中心 | 部分批次中转、分批出货、贴近项目现场节奏 |
| 货 | 保税区进出，有进出口报关单；过单，不进自有仓 | 按需要接一批、卖一点、余量后续卖 |
| 客户 | 同一石化化工流程控制链条（厂、代理商、总包、终端） | 同左 |
| 不是 | 无报关的纸面进出口、无货权的「只开票」 | 把香港公司流水全部改抬头的空壳 |

## 6. 对外可压缩成的表述（可直接改写进公司背景）

本公司从事工业自动化相关贸易，服务石化、化工等流程工业客户。业务以项目为主，兼有日常备件与零星采购。交易对手覆盖生产厂、国际品牌项目代理商及大型总包商。

香港公司作为进出口签约与结算主体：签署进出口合同，在港开票收款，货物进入保税监管场所并办理进出口报关，以过单方式履约，货物不进入自有仓库。利润留在香港公司，毛利为正常贸易加价，而非通道过账。

因项目到货与现场领用、后续零星销售不同步，部分批次由内地公司中转接货并分批销售，以降低保税仓储费用、匹配出货节奏。内地中转以真实后续销售为前提。
