# EA10 产品定义（Step 1 冻结）

**型号：** EA10  
**名称：** 智能多回转电动执行机构（开关/定位）  
**首台用途：** 闸阀、截止阀、带推力阀杆的切断阀；配二级减速后也可带小口径蝶阀/球阀。

---

## 1. 性能指标

| 项目 | 冻结值 | 备注 |
|------|--------|------|
| 额定力矩 | **100 N·m** | 开、关方向独立可设 40–100% |
| 堵转/解座 | **1.5× 额定**（150 N·m） | 离座一小段旁路力矩开关；仍不动则卡死停机 |
| 输出转速 | **18 r/min**（50 Hz） | 计算速比按四极电机 1400 r/min |
| 工作制 | S2-15 min，Class A/B | 平均负载 ≤ 33% 额定；启动次数 ≤ 60 次/h |
| 电源 | 3 相 380 V ±10%，50 Hz | 自动相序；缺相保护 |
| 电机 | 四极笼型，S2，F 级绝缘 | 机座按 Step 2 计算，目标 ≤ 0.55 kW |
| 手轮 | 侧置，离合后与电机脱离 | 可挂锁；手轮动作由编码器记录 |
| 连接 | ISO 5210 **F10** | 输出型式 **A**（推力、阀杆螺母）与 **B1**（转矩） |
| 阀杆通孔 | A 型 **φ20 mm**（F10 上限） | 已冻结，不改 F14；螺母 Tr20×4 可换 |
| 防护 | IP66 / **IP68（7 m，72 h）** | 双密封：端子舱进水不得进入电子/齿轮舱 |
| 温度 | −25～+70 °C（首台） | 低温包、高温包后置 |
| 防腐 | ISO 12944 **C4**，外紧固件 316 | 沿海 C5 后置 |
| 位置检测 | 无接触绝对编码，失电保持 | 量程 ≥ 500 圈（首台按 200 圈软件限） |
| 力矩检测 | 蜗杆轴向力 → 应变/压电 | 与位置通道独立 |
| 就地操作 | 旋钮磁耦合，非侵入 | 开/关、就地/停止/远方 |
| 远方 | 开/关/停硬线 + 4 组状态触点 | 总线、4–20 mA 位置后置 |
| 加热器 | 控制仓防凝露，常配 | — |

不在首台承诺：现场总线、蓝牙设定、SIL、隔爆、调节 1200 次/h、连续变频。

        │  双密封壁                                     │
端子舱 ─┤  （格兰可漏，水停在本舱）                      │
        └──────────────────┬────────────────────────────┘
                           │ 密封隔板
        ┌──────────────────┴────────────────────────────┐
        │  电机（可拆法兰）  蜗杆  油浴  蜗轮  锤击间隙   │
        │  手轮离合器（侧）                               │

                      ISO 5210 F10  → 阀门

三道密封面必须在 Step 3 总图上各自成环：端子盖、隔板、齿轮箱分型面。

## 3. 控制逻辑（最小集）

1. **限位关断 / 力矩关断** 开、关方向独立。软密封阀：关用限位，力矩只保护。  
2. **锤击**：电机先空转过间隙再打阀杆。  
3. **解座旁路**：离开关位可配置行程内允许 1.5 倍力矩。  
4. **瞬时反转延时**：避免换向冲击。  
5. **热保护**：绕组恒温器，冷却后才允许再启动。  
6. **相序**：检测并内部纠正，接线不必对相。  
7. **卡死**：解座段仍无位移 → 停机，报过力矩/卡死。  

调节 PID、bang-bang 定位留给 EAM，不进 EA10 首台固件。

## 6. 样机成功判据（Step 8 用）

1. 额定 100 N·m 连续走满 S2-15 min，绕组温升不超过 B 级限值（F 级绝缘按 B 用）。  
2. 解座 150 N·m 可重复 50 次，无断齿、无编码器丢步。  
3. 端子舱注水，电子仓与油浴无进水。  
4. 失电手轮 10 圈，上电后位置误差 ≤ 1° 输出轴。  
5. 软密封模拟负载：限位关断，力矩未到设定值。
