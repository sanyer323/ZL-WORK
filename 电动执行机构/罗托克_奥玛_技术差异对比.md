# 罗托克（Rotork）与奥玛（AUMA）电动执行机构技术差异对比

**对象：** 工业阀门用智能电动执行机构（多回转 / 角行程）  
**对标产品：** Rotork **IQ3 Pro / IQT3 Pro** 族 vs AUMA **SA/SAR + SQ/SQR + AM/AC 01.2** 族  
**依据：** 厂家公开样本（Rotork PUB002-197 / PUB002-406；AUMA SA/SQ/AC 产品页及技术数据），EN ISO 22153 / EN 15714-2 工作制分类  
**用途：** 规格书编写、品牌比选、备件与维保策略。投标前须用当期样本复核力矩、转速与认证条款。

---

## 1. 先看结论

两家都是重载智能电动执行机构的第一梯队，都能满足隔爆、IP68、现场总线、SIL、非侵入式设定。真正拉开差距的不是“能不能用”，而是**结构哲学**：

| 维度 | 罗托克 Rotork IQ3 Pro | 奥玛 AUMA SA + AC/AM |
|------|----------------------|----------------------|
| 设计思路 | **一体化（monoblock）**：电机、减速、控制、密封做成一套“装上就能忘”的整机 | **模块化**：电机、齿轮箱、控制单元可拆可换；控制头可墙装远置 |
| 最强项 | 双密封端子舱、施工期防进水、油气/潮湿工况“少维护” | 现场换件、振动/高温远置电子、调节工况与变频调速选项更全 |
| 最弱项 | 大修多半换整机或返厂；控制电子与阀体同振 | 接线舱密封更依赖施工质量；堆叠高度通常更大 |
| 一句话选型 | 潮湿、易淹、安装质量不可控、希望少碰盖 → **罗托克** | 调节频繁、空间别扭、要现场改速比/换电机、备件要拆得开 → **奥玛** |

**不要**把开关型（Class A/B）拿去当调节阀用。罗托克要写 **IQM / IQT3M**，奥玛要写 **SAR / SQR**。接触器寿命和电机温升都会在几个月内暴露。

## 2. 产品族对照

### 2.1 罗托克（英国 Bath）

控制电子与机械是一体的。IQ3 Pro 在 IQ3 上加了 App / 以太网 / 云端资产平台（iAM）。

| 系列 | 行程 | 工况（ISO 22153） | 直连力矩（约） | 要点 |
|------|------|-------------------|---------------|------|
| **IQ3 Pro** | 多回转 | A/B，≤60 次/h | 14–3 000 N·m | 三相开关/定位；配 IB/IS 减速可到数万 N·m |
| **IQ3S Pro** | 多回转 | A/B | 约 10–450 N·m | 单相 |
| **IQ3D Pro** | 多回转 | A/B | 视规格 | 直流 |
| **IQ3M / IQ3ML Pro** | 多回转 / 直行程 | C，最高约 **1 200 次/h** | IQM 约 11–544 N·m | 固态换向，适合调节 |
| **IQ3H Pro** | 多回转 | 高速开闭 | — | 需要快关，不是连续调速 |
| **IQT3 Pro** | 角行程 | A/B，≤60 次/h | 约 50/125–3 000 N·m | 直流电机 + 固态调速；开/关方向速度可独立设 |
| **IQT3M Pro** | 角行程 | C，最高约 **1 800 次/h** | 同上量级 | 调节型角行程 |
| **IQT3F Pro** | 全回转 / 多口 | 含调节选项 | 50–3 000 N·m | 多路阀、节流阀 |
| **CK** | 多回转 | 可配或不配一体控制 | — | 罗托克自己的模块化线，用来打奥玛的模块市场 |
| **CMA / CVA** | 角行程 / 直行程 | 连续调节 | 小力矩 | 精小型调节，不是 IQ 重载 |

网络侧另有专有环网 **Pakscan**，以及 RHS Pro 远程手操站（最远约 100 m）。

### 2.2 奥玛（德国 Müllheim；国内常称奥玛/AUMA）

机械本体与控制装置分开订货、分开更换。

| 系列 | 行程 | 工况 | 力矩（约） | 要点 |
|------|------|------|-----------|------|
| **SA .2** | 多回转 | A/B，S2-15 min（可选 S2-30 min） | **10–32 000 N·m** | 开关型主力；转速约 4–180 r/min |
| **SAR .2** | 多回转 | C，S4-25%（可选 S4-50% / S5-25%） | 约 15–4 000 N·m | 调节型；最高约 **1 200 次/h** |
| **SQ .2** | 角行程 | A/B，S2-15 min | 50–2 500 N·m | 90° 时间约 4–100 s；转角 75–105° |
| **SQR** | 角行程 | C | — | 调节型角行程 |
| **SAV / SARV** | 多回转变频 | 开关 / 调节 | 约 10–1 000 N·m | **连续调速**：中行程快、近关位慢，减水锤 |
| **GS / GK / GST / GHT** | 齿轮箱 | — | 可把输出抬到极大 | 与 SA 组合覆盖大口径蝶阀/球阀 |

控制装置单独选：

| 控制 | 定位 | 典型用户 |
|------|------|----------|
| **AM 01.1** | 开/关/停 + 少量反馈；拨码设定 | 只要硬接线、要压成本 |
| **AC 01.2** | 菜单/蓝牙/现场总线、数据记录、PID、诊断 | 智能站、总线、要力矩曲线 |
| **AC 01.2-SIL** | 额外 SIL 模块，紧急时旁路标准逻辑 | ESD / 安全仪表回路 |

电气连接默认 **插头/插座**（可改端子）。控制单元可装在执行器上，也可装到 **墙托**，用电缆远置。

## 3. 结构与密封（差异最大）

### 3.1 罗托克：双密封端子舱

IQ 把接线端子做成独立“前舱”，与内部电子、电机舱之间再隔一道防水壁。

- 防护：**IP66 / IP68（7 m / 72 h）**，不依赖端子盖或格兰是否完美。
- 施工期电缆没封好、导管进水，水停在端子舱，**控制板不一定死**。
- 就地旋钮磁耦合，设定不必开盖（非侵入）。
- 代价：电子与阀同振动；现场很少拆到“只换电机”。

### 3.2 奥玛：O 形圈 + 插头，电子可搬走

- 防护同样到 **IP68**，靠法兰面 O 形圈和插头密封。
- 插头拔掉即可断电检修，换机快。
- 密封对安装纪律更敏感：插头没压到位、格兰不合格，进水路径更直接。
- **控制头墙装**是原生能力：高温管线、强振压缩机出口、地坑阀门，把 AC 放到操作层。罗托克用 RHS 远程手操，电子仍在阀上。

**工程含义：** 电缆施工不可控、阀井易淹 → 规格书写清“双密封、接线舱与电子舱隔离”（实质偏向罗托克）。阀位难上人、要远置电子 → 写清“控制单元可墙托安装”（实质偏向奥玛）。

## 4. 位置与力矩检测

| 项目 | 罗托克 IQ3 Pro | 奥玛 SA/SAR |
|------|----------------|-------------|
| 位置 | 专利无接触绝对编码器（霍尔），活动件极少；多回转可测约 **8 000 圈**；冗余自检；**失电仍跟踪位置** | 两档：① NORM 计数齿轮 + 限位开关（侵入式调限位）；② **MWG** 永磁限位/力矩变送器（非侵入，配 AC 01.2） |
| 失电后显示/记录 | 靠备用电池维持屏幕、远传和数据记录；位置本身不靠电池 | MWG/绝对编码同样失电保持位置；电池用于显示/日志一类功能 |
| 力矩 | 蜗杆轴向推力 → **压电传感器**，与电压、温度基本解耦 | 蜗杆轴向位移的机械力矩开关（传统、直观）；MWG 可给出力矩模拟量 |
| 限位与力矩是否独立 | 位置、力矩两路独立，互为保护 | 同样可独立；NORM 机型力矩开关可现场用机械方式核对 |

**工程含义：**

- 要非侵入、要力矩曲线、要总线诊断：罗托克是标配；奥玛必须点 **AC 01.2 + MWG**，不要只订 AM + 机械限位。
- 罗托克电池约 3–5 年一换。电池没电时电动操作通常仍可用，但停电期间手轮动作的显示/日志会丢，上电后要核对行程。奥玛智能机同样有电池维护。
- 压电（罗托克）温漂小、适合做阀门力矩指纹；奥玛机械力矩开关在现场用弹簧秤/对比试验更“看得见”。

## 5. 传动、电机与工作制

### 5.1 传动

两家都是蜗轮蜗杆为主，可任意安装方位。

| | 罗托克 | 奥玛 |
|--|--------|------|
| 润滑 | IQ **油浴、终身润滑**，任意方向安装 | 规格段有油脂或油；高温、长年限要按手册检查 |
| 锤击（hammerblow） | **标配间隙冲击**：电机先空转加速再打阀杆，利于闸阀解卡 | 可选；不是所有规格默认都有 |
| 解座力矩 | 可在离座一小段旁路力矩开关，解座力矩约 **1.5 倍额定**；仍不动则判卡死停机 | 同样可设力矩关断 / 限位关断；解座策略在 AC 里组态 |
| 底座 | 推力底座可拆，装阀时不必整机吊着配螺母 | ISO 5210 / DIN 法兰种类多，现场配输出型式（A、B1 等）灵活 |
| 手轮 | 侧置，离合器脱离电机；可挂锁 | 手轮一般电机运转时不跟着转；离合器形式因规格而异 |

闸阀、楔式阀长期不动再开：罗托克锤击 + 解座旁路是现成逻辑。奥玛要在订货/组态里明确解座力矩和锤击选项。

### 5.2 电机与启动

- 罗托克 IQ：专用低惯量笼型电机，约 **3 个工频周期**内到全速；堵转/启动力矩明显高于运行力矩，配锤击，电压跌落时仍较能解座。热保护用绕组恒温器，不用熔断器当主保护。
- 奥玛：IEC 标准安装型电机（如 IM B9），现场可换电机；接触器或晶闸管换向。三相缺相、错相：两家智能机都有自动相序纠正，投运时要确认已打开。

电缆截面必须按 **堵转电流（LRA）** 算压降，不要按额定电流。压降过大时，解座瞬间电子复位或转不动，两家都会出现，与品牌无关。

### 5.3 工作制（写错规格书最常见）

| 工况 | 标准类 | 罗托克 | 奥玛 |
|------|--------|--------|------|
| 切断、偶尔动 | A / S2 | IQ / IQT | SA / SQ |
| 定位、间断 | B | 同上，注意每小时启动次数 | 同上 |
| 调节 | C / S4 | **必须 IQM / IQT3M**（固态换向） | **必须 SAR / SQR**；接触器可改晶闸管 |
| 需要行程中变速 | — | IQT 开/关速度可分设；IQH 是高速不是连续变频 | **SAV / SARV 连续变频**（奥玛明显强） |

调节阀死区设太小（例如 0.5%）会导致两家都报电机过热。先查 PID 是否振荡，再查执行机构。

## 6. 控制、通信与诊断

| 功能 | 罗托克 IQ3 Pro | 奥玛 AC 01.2 / AM |
|------|----------------|-------------------|
| 设定工具 | 手机 **Rotork App**、本安蓝牙设定器 **BTST**、就地旋钮；可断电设定 | AC：大屏菜单 + 蓝牙 **AUMA CDT**；AM：拨码，功能少 |
| 专有网络 | **Pakscan** 双线环网，距离长、断线容错，水电/长输常用 | 无对等专有环网，走开放总线 |
| 开放总线 | Profibus、Modbus、FF、HART、DeviceNet；可选一体以太网（EtherNet/IP / Modbus TCP / PROFINET） | Profibus DP/DP-V2、Profinet、Modbus RTU/TCP、HART、FF、WirelessHART |
| 闭环 | IQ：bang-bang 定位；IQT / IQM：可 PID | AC 可带过程 PID、步进模式拉长行程时间 |
| 数据 | 力矩–行程曲线、温度、**三轴振动**、事件、部分行程；Insight 2 / iAM 云 | 运行数据记录、力矩/位置模拟量（MWG）；诊断深度取决于是否订 AC |
| 远方操作 | RHS Pro，复制整机界面，执行器供电，约 100 m | 控制单元墙托远置（电子搬走）或就地控制模块 |
| 多口阀 | IQT3F / Multiport 3–16 口 | 需组合或特殊方案，不是 IQ 同级现成功能 |

**DCS 集成：** 奥玛在开放现场总线上通常更好配、文件全；罗托克在已有 Pakscan 的水厂/管线里替换成本最低。Modbus 寄存器表两家不同，换品牌等于改点表，不是“力矩法兰对上就能换”。

## 7. 安全与认证

| | 罗托克 | 奥玛 |
|--|--------|------|
| 功能安全 | IQ / IQT 有 SIL 2/3 选项（Stayput / Move），独立安全手册 | **AC 01.2-SIL**：安全功能走独立 SIL 模块，紧急时旁路 AC 常规逻辑；单通道 SIL 2，冗余 SIL 3（TÜV） |
| 安全功能 | 保持/动作到安全位，视证书 | Safe OPEN/CLOSE（ESD）、Safe STOP、安全限位反馈 |
| 防爆 | ATEX / IECEx / FM / UKEx 等，IIB/IIC | ATEX / IECEx 及国内防爆；Ex 机型控制为 ACExC |
| 防护 | IP66/68，7 m / 72 h | IP68（具体水深/时长以样本为准） |
| 防腐 | 环氧体系，规格书宜写 ISO 12944 C4/C5 与 316 外紧固件 | **KN / KS / KX** 防腐等级写进型号，KS 常用 |
| 环境温度 | 典型约 −50～+70 °C（视密封件） | 典型 −30～+70 °C，低温/高温包另订 |
| 防火 | 部分规格有火灾耐受试验证书 | 按项目另订防火箱/涂层 |

SIL 回路不要只写“智能型”。罗托克要写 SIL 选项及 Stayput/Move；奥玛要写 **AC-SIL + 安全功能清单**，并规定 ESD 用低有效 24 V 硬线。

## 8. 变频与过程控制（奥玛更完整）

需要“中行程快、关阀前慢”时：

- **奥玛 SAV/SARV**：电机变频，速度连续可设，软启动、对电网冲击小，关阀末端降速减水锤。水电、长输截断、大口径蝶阀常用这一条压罗托克。
- **罗托克**：IQT 可独立设开、关速度；多回转 IQ 主要是固定转速档位；IQH 是高速开闭，不是全程曲线调速。闭环定位 IQ 用 bang-bang，IQM/IQT 才用 PID。

大口径液动/气动替代成电动、又怕水锤时，规格书应直接写变速曲线，而不是只写力矩。

## 9. 维护、备件与寿命成本

| | 罗托克 | 奥玛 |
|--|--------|------|
| 现场可换件 | 推力底座、端子、部分电子模块；电机与减速高度集成 | **电机、控制单元、MWG、齿轮箱**可分拆 |
| 故障策略 | 潮湿损坏少；真坏了倾向整机互换或返厂 | 备件颗粒细，仓库可只备电机和 AC 头 |
| 润滑 | 油浴，常规“免维护” | 按规格查油/脂周期，尤其高温 |
| 培训 | 菜单、App、Insight 一套体系 | AM 与 AC 两套；AC 菜单深，但模块概念好教 |
| 改造旧阀 | 法兰 ISO 5210 可对；驱动螺母常要厂配或现场配车 | 输出型式、法兰组合多，非标阀杆现场更好配 |

全厂宜统一一个品牌。混用等于两套设定器、两套点表、两套培训。差价几个百分点通常抵不过运维成本。

## 10. 场景怎么选

| 场景 | 更合适 | 原因 |
|------|--------|------|
| 阀井、潮汐、施工期导管进水 | **罗托克** | 双密封，接线失误不容易灌到控制板 |
| 压缩机出口、高温蒸汽、强振 | **奥玛** | AC 墙装，电子离开阀 |
| 调节阀、风门、滤池反洗调节 | **奥玛 SAR** 或罗托克 **IQM** | 必须调节型；高精度、高启停奥玛选项更全 |
| 要关阀减速、防锤 | **奥玛 SAV/SARV** | 连续变频是现成产品 |
| 切断闸阀、少动作、“装上不管” | **罗托克 IQ** | 锤击 + 双密封 + 油浴 |
| 地坑阀门、人上不去 | 奥玛墙装控制 **或** 罗托克 RHS | 前者搬电子，后者只搬操作面板 |
| 已有 Pakscan | **罗托克** | 环网和主站已沉没成本 |
| 只要硬接线开停、预算紧 | **奥玛 AM** | 不要为简单切断买满配 AC/IQ |
| 多口选择阀 | **罗托克 IQT3F** | 现成 3–16 口逻辑 |
| 国内电厂、水务大量在役奥玛 | **奥玛** | 备件、服务、检修习惯连续 |
| 油气站场、潮湿沿海 | 两家都能用；密封条款写死则常落到罗托克 | 把“双密封”写进技术协议 |

## 11. 规格书应写死的条款（避免“或同等”被换掉）

只写“Rotork IQ3 或同等”而不写同等条件，承包商可以交出力矩够、诊断和密封差一档的产品。建议至少写：

1. **工作制**：ISO 22153 Class A/B 或 C；调节必须固态换向或晶闸管，并给出最大启动次数。  
2. **防护**：IP68；若要罗托克级防进水，写“接线舱与电子舱隔离的双密封，防护不依赖格兰”。  
3. **非侵入**：力矩、限位、控制逻辑开盖外可设；防爆区设定器要本安。  
4. **位置**：失电绝对位置保持；多回转圈数覆盖阀门全行程 + 余量。  
5. **力矩**：开、关方向独立可设；位置关断与力矩关断可组态（软密封阀用位置关断 + 力矩保护，金属密封阀才力矩关断）。  
6. **电机保护**：绕组恒温器；三相缺相/错相保护与自动相序。  
7. **加热器**：户外、潮湿必配防凝露。  
8. **总线**：写协议、冗余、ESD 硬线是否并行。  
9. **数据**：力矩–行程曲线可下载，事件容量下限。  
10. **防腐**：ISO 12944 等级 + 外露紧固件 316。  
11. **SIL**：安全功能名称、SIL 等级、Stayput 还是 Move。  
12. **电缆格兰**：IP68 认证格兰；不承认普通填料。  
13. **电源**：按堵转电流校核压降，启动压降限值（例如不超过 10–15%）。  
14. **接口**：ISO 5210 法兰规格、输出型式、阀杆螺母材质与螺纹。

## 12. 选型计算（两家通用，品牌不管）

1. 向阀门厂要 **解座、运行、关座** 力矩（或推力），长期不动的闸阀解座按 1.5–2 倍运行力矩考虑。  
2. 安全系数：清洁介质约 1.25；污水/浆液约 1.5–2.0。  
3. \(T_\text{需} = T_\text{阀} \times SF\)。执行机构额定力矩落在 \(T_\text{需}\) 的约 40–90%，不要顶格。  
4. 行程时间：多回转 \(t = N / n\)（圈数 / 输出转速）。要防锤就加长 \(t\) 或要求末端减速。  
5. 电源：电压、相数、频率；电缆按 LRA；户外加防凝露和防晒。  
6. 软密封蝶阀/闸阀：**位置关断**，力矩只做保护。力矩关断会压坏橡胶。

罗托克与奥玛的 ISO 5210 法兰在同规格下机械可互换，但电气端子、总线点表、设定工具不可互换。改品牌按新仪表回路做，不要当“换电机”。
