# EA10 传感方案（Step 5 冻结）

位置与力矩必须两路独立。电池只养屏幕和日志，**不养位置**。  
校核：`python3 sim/sense.py`

---

## 1. 位置：单圈芯片 + 韦根多圈

装在空心输出轴上端、油封之上的干腔（齿轮箱顶、控制仓下）。油不得进此腔。

| 项 | 冻结 |
|----|------|
| 单圈 | **AS5047P**，14 bit，SPI，5 V |
| 磁铁 | 径向充磁 N35，**Φ8×2.5**，粘在轴端凹台，跳动 ≤ 0.15 mm |
| 气隙 | **1.0 ± 0.3 mm**（芯片封装面到磁铁） |
| 多圈 | **韦根 + FRAM 模组**（iC-PVS 或国产等效），SPI 或脉冲，**12 bit / 4096 圈** |
| 软件行程 | 默认 200 圈，上限 500 圈（产品定义） |
| 失电 | 单圈靠磁铁绝对角；多圈靠韦根脉冲写入 FRAM，无主电也能计圈 |
| 分辨率 | 14 bit × 200 圈 → 阀位 LSB ≈ 0.00003%，远小于 0.1% |

备选（韦根模组买不到时）：输出轴 500:1 两级塑料齿轮 + AS5600，500 圈输出对应多圈磁铁 1 圈。齿隙可忽略。不作为首选。

布置：上 6010 之上把轴颈收到 Φ20 → FB 20×32×7 把油隔在下面 → 轴端磁铁 → PCB 距 1 mm，三颗 M3 吊在箱盖。PCB 线从干腔进控制仓，不经过端子舱。

上电：读多圈 + 单圈，合成 32 bit 位置。手轮动作同样被记录。

---

## 2. 力矩：蜗杆轴向垫圈

夹在左侧 **7204AC 外圈与箱体** 之间（Step 4 已留位）。测的是蜗杆轴向力，再换算输出力矩。

| 项 | 冻结 |
|----|------|
| 型式 | 轮辐/垫圈式应变全桥，**0–1 kN** |
| 尺寸 | 内孔 **Φ21**（轴 Φ20 穿过），外径 Φ42，厚 **8 mm** |
| 桥路 | 350 Ω，**2.0 mV/V**，激励 5 V → 满量程 10 mV |
| 额定工况 | Fa≈178 N（100 N·m），约 1.8 mV，只用到量程 18% |
| 解座 | Fa≈267 N |
| 锤击峰值 | 量程 1 kN 覆盖，超 0.9 kN 软件削波并记事件 |
| ADC | **ADS1220**，PGA 32，24 bit，20 SPS |
| 换算 | \(T_\text{out} = F_a \cdot (d_1/2) \cdot i \cdot \eta\)，η 取 0.40（与定型一致） |
| 温度 | 垫圈旁 NTC 10 k；固件按标定表补 |

标定（台架，力沿蜗杆轴线）：0 / 200 / 500 / 1000 N，写进 MCU。禁止用阀位反推力矩来“标定”。

## 3. 独立与失效

| 故障 | 允许的停机方式 |
|------|----------------|
| 编码丢失 | 只准力矩关断 + 热保护，禁止盲走满行程 |
| 力矩丢失 | 只准限位关断，力矩保护退出并报警 |
| 两路都丢 | 禁止电动，只准手轮 |

软密封阀：关方向 **限位关断**，力矩只做保护（阈值 110%）。金属密封：关方向力矩关断。

## 4. 门槛（已过）

`python3 sim/sense.py`：阀位 LSB ≪ 0.1%；多圈 4096 ≥ 500；解座力 < 1 kN；额定点 ADC 计数远大于 1 N·m 设定步进。
