# EA10 固件最小集（Step 7 冻结）

实现：`fw/ea10_fsm.c`（可移植状态机）· 逻辑自测 `python3 sim/fsm.py`  
MCU、引脚、接触器见 `06_控制电子.md`。不做蓝牙、总线、PID。

---

## 1. 状态

`STOP → OPENING / CLOSING → OPENED / CLOSED`，任意可进 `FAULT`。  
选择开关 `LOCAL / OFF / REMOTE`。OFF 与远方 STOP、就地停：立即释放接触器。

停优先于开/关。手轮微动断开：禁止电动。

---

## 2. 动作规则

| 条件 | 行为 |
|------|------|
| 开指令 | 吸合 K_open；锤击段（蜗杆 12°，约 14 ms@1400 r/min）不判过力矩 |
| 关指令 | 吸合 K_close |
| 软密封关 | **限位关断**（关位 ±0.5%），力矩 ≥110% 才故障 |
| 金属密封关 | 力矩关断（设定值），限位作备份 |
| 开到位 | 开限位 |
| 解座旁路 | 离开座位 5% 行程内允许 150% 力矩；仍无位移 0.4 s → 卡死故障 |
| 瞬时反转 | 先全释放 **≥80 ms** 再反向 |
| 相序 | 上电测 L1/L2/L3 过零顺序，对调开/关接触器映射 |
| 缺相 | 0.3 s 无某相 → FAULT_PHASE |
| 热保护 | 恒温器开路 → FAULT_THERM，冷却后才允许复位 |
| 编码丢失 | 禁止电动，FAULT_POS |
| 力矩丢失 | 禁止力矩关断，只准限位，报 WARN_TORQUE |
| 卡死 | FAULT_JAM |

复位：选择开关打到停，再打就地/远方。故障触点保持到复位。

---

## 3. 事件记录

环形 256 条，掉电靠 FRAM/RTC（CR2032）。每条：时间、状态、位置 0.01%、力矩 N·m、故障码。  
不上云、不蓝牙。LCD 可翻看最近 20 条。

---

## 4. 周期

主循环 5 ms。接触器输出有 20 ms 滤波。力矩 20 SPS（ADS1220），位置每 5 ms 读 AS5047P，多圈 50 ms 或过零时读。
