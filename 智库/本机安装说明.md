# 本机安装知识库（Obsidian + 本仓库「智库」）

## 一、安装 Obsidian

在 PowerShell **整段粘贴**：

```powershell
winget install --id Obsidian.Obsidian -e --accept-package-agreements --accept-source-agreements
```

若 winget 不可用：打开 https://obsidian.md 下载安装。

## 二、拿到带「智库」的仓库

```powershell
cd $env:USERPROFILE\Downloads
if (Test-Path ZL-WORK\.git) {
  cd ZL-WORK
  git stash push -u -m "temp" 2>$null
  git checkout main
  git pull origin main
} else {
  git clone https://github.com/sanyer323/ZL-WORK.git
  cd ZL-WORK
}
explorer .\智库
```

## 三、用 Obsidian 打开

1. 打开 Obsidian  
2. **打开本地仓库** → 选文件夹：  
   `C:\Users\sanye\Downloads\ZL-WORK\智库`  
   （若仓库在 Desktop，就选 Desktop 下对应路径）  
3. 打开笔记「首页」

## 四、开始喂养

在 Cursor 里说：

```text
按 domain-think-tank：往「智库/金融股票」增量写入今天可复用要点。
```

或设好 Automation（见 `AI研发产品/docs/kb/automation-智库持续喂养.md`，写入路径已改为仓库根目录 `智库/`）。

## 五、合进 GitHub 之后本机仍看不到

Obsidian 打开的是 **`C:\Users\sanye\Downloads\ZL-WORK\智库`**，不是桌面 `日常` 那份工作副本。GitHub `main` 合完 PR 后，在这份克隆里执行：

```powershell
cd $env:USERPROFILE\Downloads\ZL-WORK
git checkout main
git pull origin main
```

然后在 Obsidian 点「首页」或切一次笔记。

本机已挂号钟：每天 21:40、08:00 自动把这份 Downloads 库快进到 GitHub `main`。也可手动跑 `智库\sync-from-github.ps1`。
