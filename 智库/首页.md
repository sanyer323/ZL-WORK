# 我的 Cursor 智库

这是给 **人看** 的知识库（Obsidian）；Cursor / Automation 也会往这里 **增量写入**。

## 怎么打开

1. 安装 Obsidian（见同目录 `本机安装说明.md`）
2. Obsidian → **打开本地仓库（Open folder as vault）**
3. 选中本文件夹：`智库`（在 ZL-WORK 仓库里）
