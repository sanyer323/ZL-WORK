# 清单与配方

> 领域：健康保险。增量追加，勿整篇清空。条目建议带日期。

## 2026-10-11 腰椎门诊怎么问（带着片子）

缺一项就先别自己下结论：

1. 当前腰痛以**轴性腰痛**为主，还是已有腿麻/窜痛/无力？
2. L5–S1 中央型突出 + 硬膜囊/神经根受压变形，和站走跑疼痛是否对得上？
3. 要不要补 **腰椎 MRI**？若要，看什么（神经根、椎间盘、韧带）？
4. 近期能不能继续跑步/负重？活动边界怎么划？
5. 保守方案大概包括哪些（康复训练、药物、局部治疗）？复诊间隔多久？
6. 出现哪些变化要提前回诊或急诊？

## 2026-10-11 红旗症状（尽快就医/急诊）

出现任一即优先就医，不在此罐里「观察再说」：

1. 大小便困难或失禁  
2. 会阴区麻木  
3. 下肢明显进行性无力、足下垂  
4. 发热伴剧烈腰背痛  
5. 外伤后急性剧痛/不能站立

## 2026-10-11 服药与复诊自检（非医嘱）

1. 按处方疗程吃完，不自行加倍「好得快」。  
2. 记录：哪天开始痛感减轻/加重、有无腿麻无力新发；有无胃痛/黑便等。  
3. 复诊时带：CT 云影像/报告、本次处方与发票。  
4. 药名已入库（双氯芬酸钠缓释片、汉防己甲素片）；若处方上还有别的药再补一行。  
5. **当前不做牵引**（医生已明确）；若别处建议牵引，先回开方医生确认后再说。  
6. 勿自行再加布洛芬等同类消炎止痛药叠吃。

## 2026-10-11 保险核对清单（有保单再填）

1. 险种与保单号、承保公司、生效/满期日  
2. 等待期是否已过；本次症状/影像是否落在等待期内  
3. 健康告知：投保时是否已披露腰部不适/影像；有无「既往症」相关条款  
4. 责任：门诊/住院/手术各自怎么赔；免赔额、赔付比例  
5. 材料：报告、发票、病历、影像光盘/云链接、身份证与银行卡  
6. 理赔路径：App/柜面/经纪人；预计时效；拒赔时复议入口  

## 2026-10-12 买港司跨境门诊前必问（缺一项就停）

1. **保障地域**：内地是否含**杭州**日常门诊（不是只写「大湾区/中国」宣传语）？上海是否一并写清？  
2. **门诊利益**：赔付比例是否真是 **100%/全数**？每次上限、每年次数、年额、自付额、中医/骨科专科是否另计？  
3. **承保主体/产品名**：安盛天平「卓越环球」？工银安盛「寰球尊享」？还是安盛香港 EB 定制？别只说「安盛」。  
4. **网络 vs 报销**：杭州是网络直付还是先垫付再申索？要哪些单据？  
5. **投保身份**：公司团体持有 vs 个人保单+公司报销——税务谁确认过？  
6. **既往症（腰椎）**：是终身除外、加费仍保、等待期后保，还是拒保？除外文字是否宽到「腰腿痛/神经根」？续保会不会因索赔涨价或不再续？  
7. **港侧**：香港普通科/专科网络免找数有没有？  
8. 尽量拿到朋友同款保障表复印件对照；书面保障表齐了再付款。  

## 2026-10-11 对话禁区（给 AI）

- 不替代医生诊断或开药方、手术建议。  
- 不承诺某张保单「一定赔」或「一定拒」。  
- 可做：白话解释报告用词、列问题、记时间线、对照条款关键词待主人核实。

## 2026-10-12 俄疫多源日报自检

每天跑简报前勾一遍（详见 `AI研发产品/docs/kb/automation-俄疫多源日报.md`）：

1. 官方（卫监局/州长/克宫）说了什么？  
2. WHO/ECDC 有无新 DON 或风险措辞变化？  
3. Meduza / Reuters / BBC / NYT / 本地调查有无与官方冲突的点？  
4. 「第二例」「实验室事故」「病原确认」分别是：有 / 无 / 未证实？  
5. 写入 `事实与坑` 带日期节；无新料则只写开放问题，不灌水。
