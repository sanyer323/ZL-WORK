# 清单与配方

> 领域：编剧。增量追加，勿整篇清空。条目建议带日期。

## 2026-09-20 一组分镜卡（原理或排故都用这 6 格）

写旁白前先填卡，填不齐就还没到可渲：

1. **本段系统问题**（一句话，观众看完能答）
2. **画面必须看见的变化**（间隙、压力、滑阀、阀位……必须有状态差，不能只是零件静照）
3. **旁白只补画面说不清的因果**（少形容词）
4. **收口一句**：原理版写机理要点；排故版写现场先查哪
5. **手册出处与数字**（电压 / 压力 / 电流 / 间隙对得上哪一节）
6. **禁止混入**：另一口吻、营销 CTA、另一张极性表
