# 清单与配方

> 领域：编剧。增量追加，勿整篇清空。条目建议带日期。

## 2026-09-20 一组分镜卡（原理或排故都用这 6 格）

写旁白前先填卡，填不齐就还没到可渲：

1. **本段系统问题**（一句话，观众看完能答）
2. **画面必须看见的变化**（间隙、压力、滑阀、阀位……必须有状态差，不能只是零件静照）
3. **旁白只补画面说不清的因果**（少形容词）
4. **收口一句**：原理版写机理要点；排故版写现场先查哪
5. **手册出处与数字**（电压 / 压力 / 电流 / 间隙对得上哪一节）
6. **禁止混入**：另一口吻、营销 CTA、另一张极性表

## 入库纪律

- 只收会改变下次怎么写旁白的骨架和坑；金句、一次性修辞不进。
- 不把分镜全文或 docx 脚本搬进本罐；正文仍在 `AI研发产品/研发仿真视频/`。
- 没有影视编剧 skill 就不新建空文件；和 FY301 仿真重叠的短规矩进 `positioner-rd`。
## 2026-09-24 一段工业旁白怎么写
动手写词前，按顺序过：
1. **先写画面。** 观众把声音关掉，还能指认这是哪一个零件、哪一股气？指认不了，先改分镜。
2. **本段只做一件因果。** 写完用半句话概括；概括里出现两个「并且」，就拆段。
3. **选定口吻。** 原理 / 排故 / 卖货三选一。原理段用「所以/于是」接因果；排故段用「先查/不要先怪」；卖货段不要混进前两种。
4. **数字四件套。** 数值 + 单位 + 来源手册 + 极性（默认 FY301ME）。缺一件先空着，不许编。
5. **路标一行。** 原理用「本段要点」，排故用「现场结论」。只写信号，不把旁白再缩抄一遍。
6. **出声读一遍。** 读不顺的书面长句、英文缩写连念，就地拆开或先给中文名。
7. **画面上只留关键词/参数。** 全文走旁白和软字幕，不烧在图上。
## 2026-09-24 开场 10 秒检查
- 5 秒内能听出：这是什么装置、今天只讲哪一环。
- 删掉「全球知名 / 新一代 / 大脑 / 至关重要」之后，还剩没有可核对的事实？没有就整段砍。
- 章节片头只当路标（「下一段：伺服级」），不加第二轮公司介绍。
- 只写会改变下次分镜或旁白的条目；影视奖项、平台热剧、一次性新闻不进。
- 不把手册章节全文搬进本罐；数字只记「值 + 单位 + 出处 + 极性」。
- 短规矩进 `positioner-rd` 的讲解旁白条；不新建空的编剧 Skill。
## 2026-09-27 写旁白前
1. **这版口吻？** 原理 或 排故，先定再写。
2. **先列画面事件，再写口述。** 图上已有的句子，旁白改说「看哪、意味着什么」，不复读。
3. **一段只推进一步因果。** 压电、先导、滑阀、Hall、全链路分开；段首 5 秒点题。
4. **数字四件套齐了吗？** 数值、单位、条件（如供气 20 psi）、来源表（FY301ME 或 fycalme）。
5. **极性声明了吗？** 默认 FY301ME；反表必须点名。
6. **切得开吗？** 能按章节停/跳；有字幕轨 + 文稿，不把视频当唯一说明书。
- 只写会改变下次分镜/旁白的条目。
- 短规矩再提炼进 `positioner-rd`；不新建空的编剧 skill。
## 2026-10-01 写词时多问三句
动手写或改旁白时，按顺序过（前面的 6 格卡仍先填）：
1. **这句话删掉，画面还站得住吗？** 站得住就删。公司史、发现史、品牌形容词先砍。
2. **这句是在指路，还是在描外形？** 改成「看哪 + 状态差 + 意味着什么」。一句只指一个地方。
3. **画面上的字贴在被指的零件旁了吗？** 不要底部通栏。全文走旁白和软字幕。
分镜仍用两栏：左栏只写 **变前 → 变后**（必须有状态差）；右栏只写图说不清的因果和数字四件套。
- 只写会改变下次分镜/旁白的条目。
- 短规矩进 `positioner-rd`；不新建空的编剧 skill。
## 2026-10-08 写词时再问四句
前面的 6 格卡和三问仍先过。过完再问：
1. **关掉声音，图上是不是只剩术语/数字？** 若是整段句子，改回口述，图上只留短标签。
2. **这句出声时，画面是不是正好在这一状态？** 对不上就改分镜或改词，不要靠后补。
3. **这个数字出声时，图上有同一个数吗？** 没有就加上，或把这句挪到出数的那一拍。
4. **这是当前这一拍的一个数，还是把整张判据表念完了？** 整表拆拍；公文腔和带货「您」直接删。
- 只写会改变下次分镜/旁白的条目。
- 短规矩进 `positioner-rd`；不新建空的编剧 skill。仍不编官方语速字数。
