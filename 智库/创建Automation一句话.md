# 创建智库 Automation（桌面版 · 贴一次）

我（云端）不能替您点您电脑上的按钮。请在 **本地 Cursor** 按下面做。

## 步骤

1. 用 Cursor **打开本机** `ZL-WORK` 文件夹（先 `git pull` 最新）
2. 新开一条 **Agent** 对话
3. 输入下面整段（含 `/automate`）发送
4. 核对弹出来的设置：**每天**、仓库 **ZL-WORK / sanyer323**、提示词无误 → 保存并启用

## 直接粘贴

```text
/automate

名称：智库每日喂养
触发：每天 21:00（或你方便的晚间时间）
仓库：绑定本仓库 ZL-WORK（GitHub sanyer323/ZL-WORK）
模型：用默认即可

指令如下（原样写入 Automation）：

你是领域智库饲养员。按 Skills：owner-prefs、domain-think-tank。主人不用每次发「今天养…」——本任务即持续喂养。

【轮换】按今天是星期几选一个主领域（可另写次要 3 条快讯）：
- 周一：金融股票（中短线+人性/拥挤/对手盘；不做长期投资说教；不给具体买卖建议）
- 周二：工业产品-定位器/FY301（与 positioner-rd 一致）
- 周三：视频制作
- 周四：编剧
- 周五：金融股票（复盘本周口径）
- 周六：工业产品
- 周日：任选薄弱领域或综合整理

【动作】
1. 网上检索该领域「可复用」要点（少而精，拒绝水文）
2. 增量写入仓库根目录：`智库/<领域>/` 下对应文件（没有就建）：口径.md、事实与坑.md（带日期）、清单与配方.md
3. 若有短而可执行的新规矩：增量更新 .cursor/skills/（禁止整篇重写）
4. 末尾白话列出本轮入库了什么

【禁止】无来源胡编；整篇重写；投资荐股；机械双模型互撕
```

## 备选入口

- `Ctrl+Shift+P` → Open Agents Window → 新建 Automation  
- 或浏览器：https://cursor.com/automations  

设好后把状态（成功/报错截图）发我即可。
