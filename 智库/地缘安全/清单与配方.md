# 地缘安全 · 清单与配方

## 盯「核潜艇 / 囤货 / 大战叙事」时怎么拆

1. **先拆事件**：潜艇动态 ≠ 民防囤货 ≠ 政客战备演讲；各自找官方原文日期。
2. **潜艇**：分清 SSBN（战略威慑，Vanguard/Dreadnought）vs SSN（攻击艇，Astute）。「离开本土」要问：是例行巡逻接班、试航，还是罕见多艇同出。
3. **囤货**：看是不是**新运动**还是常年 Ready.gov / 防災手册；天数（3 日 / 1 周 / 数周）与场景（天气、地震、网攻）必须抄原文。
4. **三国对照表**：美日英各一格；缺格就写「未见」，禁止用二手「三国同步」填空。
5. **合成检测**：若社媒把 A+B+C 剪成一条因果，输出里单独开「合成叙事」栏。
6. **仍盯清单**：只挂可验证节点（如日本 11/2 正式要請、第三艘艇任务公开），不日更恐吓。

## 2026-11-01 周日通读 · 读「緊急要請」先问哪一层

开罐拆法已有。11/2 全文出来前、以及出来后，缺一项就停，别用一个「日本下令囤货」交差：

1. **对象是哪一层？** 国民家庭备灾、自治体备灾/研修，还是各省厅所管领域？官方 10-20 会见已经写成至少三份要請，不要合成一份「全国令」。
2. **这是要請还是勧告？** 要請是发足日第一步；勧告権是要請发出后、落实不够才考虑。文本没出来之前，不要写成已经勧告。
3. **日期是机关挂牌日，还是预报日？** 11/2 是防災庁発足日。发足日 + 「緊急」+ 备灾天数 ≠ 当天要地震/开战。
4. **美国那格有没有新的家庭通告？** 没有就写「未见」。FEMA 仓库采购或过期物资调研不要填进这一格。
5. 仍不日更恐吓；正式全文以 11/2 内阁府 / 防災庁文本为准，不以二手「三国同步」填空。

## 2026-11-08 周日通读 · 全文已出，下次先问文书强度

11-01 那五问仍成立。官方页挂上之后，缺一项就停，别用一个「日本已下令 / 已勧告」交差：

1. **打开的是哪一份 PDF？** 国民大臣消息、次官通知都道府县，还是大臣依頼府省厅？官方页三份分开挂，不要合成一份全国令。
2. **勧告写在哪一层、过了哪道门？** 官方概要把「必要に応じて勧告」写在指定行政机关跟进里；都道府县/府省厅年末才交进度。报告没出来，不要写成已经勧告。
3. **美国那格看哪一页？** 看 Ready.gov **kit** 页的 Last Updated，不要看首页改日期。没有新日期就写「未见」。
4. **英国那格是不是新令？** 仍是 10-22 Be Ready。地方议会转发不算内阁办又发了一张纸。
5. 仍不日更恐吓。来源以防災庁官方页为准，产经/FNN 转载只作对照，不当前一手。
