## 1. 一句话假设（可检验、可证伪）

同一选股规则与同一持有期下，把「触及涨停仍按目标价买入 / 触及跌停仍按目标价卖出」改成诚实成交约束（一字涨停买记未成、一字跌停卖记未成；非一字但收盘封板的买入按量能上限封顶或记未成——规则事先写死）后，**策略净值收益与计划换手会显著下降**；高换手、爱追涨的规则下降更大。主板 ±10% 与创业板/科创板 ±20% 分段对比。

证伪方向：若诚实约束组相对天真组的收益差与换手差在标定门槛内可忽略，或追涨规则并不比非追涨规则多掉一截，则本假设在该样本与撮合设定下不成立。

## 2. 可编码概念 / 因子或信号定义

### 2.1 涨跌停价与板上标签（未复权）

- 输入日 `t` 对证券 `i`：未复权 OHLC、交易所前收盘价 `pre_close`（除权/息日用交易所**除权参考价**当行情前收盘，见罐内事实与坑）、板块/风险警示标识、当日是否设涨跌幅。
- 限制比例 `pct(i,t)` 按**当时规则**切片（默认：主板普通股 10%；创业板/科创板 20%；主板 ST/*ST 在 2026-07-06 前 5%、此后 10%；科创/创业风险警示维持 20%；无涨跌幅日则本实验不标「板上」，另案处理）。
- 伪代码级：

```
tick = 0.01  # A 股股票默认最小价位；基金勿混用
raw_up   = pre_close * (1 + pct)
raw_down = pre_close * (1 - pct)
limit_up   = round_half_up(raw_up,   tick)
limit_down = round_half_up(raw_down, tick)
# 若 |limit - pre_close| < tick → limit = pre_close ± tick
# 若 limit < tick → limit = tick

is_limit_up_close   = (close >= limit_up)   # 收盘触及涨停价
is_limit_down_close = (close <= limit_down)
# 一字涨停（日频占位）：open==high==low==close==limit_up 且 volume>0
# 一字跌停：对称
# 打开板（日频占位）：曾触及涨停价但收盘未封（high>=limit_up 且 close<limit_up）；
#   无分钟线时仅作备注标签，主检验仍用收盘封/开盘一字。
```

- **禁止**：用前复权/后复权价判板；用未取整的 `pre_close*(1±pct)` 直接比收盘价。

### 2.2 「可成交」诚实约束（本实验编码）

信号在调仓日 `d` 收盘后可见；默认成交日 = **次一交易日 `d+1`**（与口径「成交时点写死」一致）。本页**建议默认成交时点 = 次日开盘价**（开盘集合竞价价；走不成再按数据商开盘定义）。次日收盘可作稳健性单列，不得与默认混报一条净值。

诚实组（A1）对 `d+1` 的买卖意图：

| 情形 | 买入 | 卖出 |
|------|------|------|
| 开盘一字涨停 | 成交量记 0（失败） | 仍可按开盘价尝试卖（若有量）；失败则按事先规则顺延 |
| 开盘一字跌停 | 仍可尝试买 | 成交量记 0（失败） |
| 收盘封涨停且非开盘一字（日频无法分辨排队） | **主设定**：买入记 0；**灵敏度**：成交量 ≤ `min(意图量, floor(κ·当日成交量))`，`κ` 占位默认 0.01（待回测岗标定，禁当真数） | 卖出按开盘价（若未一字跌停） |
| 收盘封跌停对称 | 买入按开盘 | 主设定卖出记 0；灵敏度同 κ |
| 停牌 / 全日无成交 / 成交量=0 | 不可交易；失败（行情收盘=前收盘不是可成交） | 同左 |
| 盘后固定价格 | **本实验默认关闭**；不得当成收盘无限量成交。若单列，须按板块落地日切片，且仍受对手盘/停牌约束 | 同左 |

失败后持仓规则（须事先写死，二选一写进回测配置，禁止跑后改）：

1. **顺延**：意图保留到下一可交易日再试，直到成交或信号撤销；  
2. **空仓/跳过**：该笔作废，仓位按未成交处理。

天真组（A0）：忽略涨跌停与停牌可成交性，按次日开盘价（或对照用次日收盘价）**100% 成交**。

整手约束本页不主测（见实验 E）；若引擎已实现，诚实组应保留整手截断，天真组可关，但须在报告里声明。

## 3. 样本区间

- **宇宙（默认）**：沪深 A 股股票（不含可转债、不含股票 ETF 主样本）。按日切片：交易所、板块、是否 ST、是否设涨跌幅、是否退市整理期。
- **排除（默认）**：调仓日未上市；退市整理期交易日；无涨跌幅日（本实验不强制纳入；纳入须另标临停规则）；信号日或成交日停牌且全日无成交；数据缺失无法算 `limit_up/down` 的日。
- **股票池 PIT**：每个调仓日只用**当日已生效**可交易名单（勿用核对日还上市的全 A 回放）。指数成分若作宇宙，按调样生效日。
- **区间建议**：待数据接入后锁定起止。建议复现默认（可改，须写入配置）：
  - 主窗：最近完整 5 个自然年交易日（含至少一次主板 ST 5%→10% 切日 2026-07-06 的前后各 ≥1 年，若样本够）；
  - 稳健：再切「创业板 20% 落地后」「科创板开市后」「主板注册制笼子落地后」子窗。
- **PIT 切片原则**：涨跌幅比例、ST 档、有无涨跌幅、盘后通道是否存在，一律按成交日当时规则；财务类因子若将来接入同一管线，对齐公告可见日（本实验本身是执行约束，不依赖财报）。

## 4. 标签 / 对照设计

### 4.1 对照

| 组 | 撮合 |
|----|------|
| A0 天真 | 次日开盘 100% 成交；涨跌停/停牌不挡 |
| A1 诚实-硬 | 一字涨停买=0；一字跌停卖=0；收盘封涨停买=0；收盘封跌停卖=0；停牌/无量=失败 |
| A1κ 诚实-量能帽 | 同 A1，但对「非一字、收盘封板」允许 ≤κ·日成交量（κ 占位） |

同一信号、同一持有期、同一成本开关（本页可先零成本只比执行差；成本实验见 B/S/T，勿混进 A 的主结论）。

### 4.2 成交时点（写死）

- **默认**：次日 **开盘价**。  
- **稳健单列**：次日 **收盘价**（仍受 A1 约束；停牌日失败）。  
- 禁止：不声明开/收就报一条净值；把盘后固定价格默认并进「收盘一定成」。

### 4.3 成功 / 失败判据（相对；数值门槛待回测岗标定）

主指标（均报 A1 相对 A0，及主板 vs 创业/科创分段）：

1. 年化收益差 ΔAnn、最大回撤差 ΔMDD；  
2. 计划换手 vs 实际换手、受阻买入/卖出笔数、期末残余仓；  
3. 追涨子集（信号日已涨停或高涨幅分位——定义写进配置）相对非追涨子集的 ΔAnn 是否更大。

**相对判据（草稿）**：若 A1 相对 A0 的实际换手下降 **≥ X%** 且年化收益下降 **≥ Y**（或信息比率掉 **≥ Z**），则记「执行鸿沟显著」。X/Y/Z **待回测岗用同一样本标定**，本页不填死数。  
**失败/不显著**：差落在标定噪声带内，或仅由停牌日驱动而板上日无贡献——须在结论栏写明，不得改口称为「策略仍稳健」。

结论栏：空。跑完只写「该假设下差多少」，不写「所以该买这类票」。

## 5. 预期失效条件

本假设或实验设定在下列情形下失效/须重切，不得硬套：

1. **规则切日未切片**：用现行 ±10%/±20%/ST 档铺满历史；或 2026-07-06 前后主板 ST 用同一比例。  
2. **复权判板**：用复权价或复权前收盘标涨跌停；除权日不用交易所除权参考价。  
3. **盘后当无限量**：把盘后固定价格当成涨停日按收盘价必成；或主板扩围前就当作全 A 可用。  
4. **停牌假成交**：成交量=0 日用「收盘=前收盘、涨跌幅 0」当可交易横盘。  
5. **日频无法分辨却假装有队列**：无 tick/委托簿时把「收盘封板」一律当成曾打开可任意量买入，或反过来不声明就切换 A1/A1κ。  
6. **成交时点漂移**：同一报告里混用次日开与次日收。  
7. **宇宙泄露**：用今天还上市的票或今天的指数成分回放。  
8. **标的错位**：把可转债（当日回转、板规不同）或股票 ETF 回转规则套进本股票实验。
