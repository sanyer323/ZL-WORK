## 1. 一句话假设（可检验、可证伪）

同一信号、同一未复权成交金额下，回测把**可转债转股所得股票**的印花税**误免**成 0，或因现货不征把 DC 抄到转股腿，或因结算表只列可交换换股就发明转股腿 0，或漏掉只向出让方征收，或把可交换换股表列名专条与可转债转股合成一句，或与 R股票ETF假T+0 / DC现货印花误抽 / DP可交换换股印花 / V股票二级印花切日 / CQ转股可成交性 / Q转债规则与流通时点 / DR盘后定价通道 混读，或缺业务类型或官方税目/规则仍不 skip，相对「缺业务类型或官方税目/规则则 skip；转股交割股票=出让方按《印花税法》股票转让税目，切日消费 V；禁止因现货不征（DC）或结算表仅列可交换换股（DP 消费）发明转股腿 0；禁止把可交换换股表列名专条与可转债转股合成一句」的诚实组，会**系统性改写转股所得股票腿的印花成本**——相对诚实锚偏误。误免把这条腿的印花成本吹瘦。

核对日方向（随锚写死；禁止把 0.5‰ 或法定 1‰ 写成占位门槛，也禁止把转股腿写成免费 0）：转股交割与现货分开，转股与可交换换股分开，印花与可成交性、流通时点、盘后通道分开。`事实与坑` 2026-11-09 已写：换股/转股交割的是股票，那笔走股票印花税，不要和现货捆成「转债相关都不抽」。《印花税法》税目是转让股票和以股票为基础的存托凭证，只向出让方征收；法定千分之一，以及 2023-08-28 起减半，都只消费 V，本页不重开 V。结算代收表把可交换公司债换股列进印花税品种、没有可转债现货——现货「不征」留给 DC，换股专条留给 DP。看见表上没有「可转债转股」这一行，不能据此发明转股腿 0，也不能把可交换换股那一行和可转债转股合成一句。缺业务类型，或官方税目/规则对不上，整腿 skip，不用现货不征、换股专条、占位 0.01 或自造‰去填。能不能转成留在 CQ，次日才流通留在 Q，盘后定价通道留在 DR，股票 ETF 假 T+0 留在 R。**禁把占位读成印花 0.5‰/1‰**。**`params.G` 的 0.01 ≠ 印花 0.5‰ ≠ 法定 1‰**。**params 相对门槛 ≠ 印花税率**。**禁与 DC/DP/V/CQ/Q/DR/R 混读**。

证伪方向：若天真组 / 半泄露组相对诚实组的转股印花误免截在标定噪声带内可忽略，且「抄现货不征 / 因表只列可交换换股而发明 0 / 漏出让方 / 合成一句 / 核对日泄露 / vs DC·DP·V·CQ·Q·DR·R」分桶不改变结论，则本假设在该样本与开关设定下不成立。
