> 增量笔记。不荐股、不写买卖标的/仓位、不依赖聚宽真数、不跑回测结论。与 `口径.md` / `事实与坑.md` / `清单与配方.md` 实验 H 对齐。与假设 A（板上成交）、G（无涨跌幅日 PIT）、C（股票池当时名单）互补：本页专测**退市整理窗口**被当成「普通可交易日」或「已停牌横盘」时，对摘牌前收益与指数回测的扭曲。

---

## 1. 一句话假设（可检验、可证伪）

同一信号、同一持有期、同一 T+1 下，把退市整理期当成普通可交易日（涨跌停用板块默认比例，含整理首日误套 ±10%/±20%），或当成停牌（收益填 0、不可新开仓），相对「标成整理窗口：首日不套涨跌停买入约束、其后用当时板块限制、指数权重当日剔除」的诚实组，**净值、失败笔数与整理期贡献的那截收益会显著偏离**；把现行 15 个交易日铺满 2020 年底退市新规之前（当时 30 日）会再叠加窗口长度错切。

证伪方向：若天真组 / 停牌化组相对诚实组的净值差、失败笔数差、整理期贡献差在标定噪声带内可忽略，且 15/30 日错切不改变结论，则本假设在该样本与撮合设定下不成立。

## 2. 可编码概念 / 定义

### 2.1 退市整理窗口（按成交日当时规则；未复权）

```
# 配置写死（见 §7）
exit_period_len_source = rule_cut_20201214   # 切日前 30 交易日；切日后 15 交易日
# params.exit_len_cut_date 写死默认 2020-12-14（上交所退市制度答记者问：30→15 并新增首日无板）
# 拉数前冻结；禁 holdout / 事后改切日

def exit_len(asof_date):
    if asof_date < params.exit_len_cut_date:
        return 30
    else:
        return 15

# 整理期日历：自进入退市整理起计 exit_len 个「计入」交易日
# 全天停牌不计入（上交所 4.4.3；累计停牌上限另记，本页最小集：停牌日不推进计数）
# 届满后 N 个交易日内摘牌（上交所现行 5 日；本页摘牌日用数据商/公告 delist_date，不另发明）

is_exit_day(i, t)     = exit_start(i) <= t < delist_date(i) and in_counted_window
is_exit_first_day(i,t)= is_exit_day and (t == first_counted_trading_day)
# 首日：不实行涨跌幅限制（上交所 3.3.13 / 深交所 3.3.15；与假设 G 无板表一致）
# 首日之后：回到该板块当时限制（主板 10%；创业板/科创板 20% 按切日；勿整段当无板）
```

- **指数**：整理期交易**不纳入本所指数**（上交所 4.4.12；深交所 4.5.7）。诚实组指数权重当日剔除；成交量可计入市场总量（本页不主测总量）。  
- **50 万股买入上限**：规则写的是**风险警示股票**（上交所 4.4.10；深交所 4.5.4），**不要自动套到退市整理股**；科创板风险警示/退市整理不进风险警示板——**本页默认 `risk_warn_buy_cap_50w=off`（不主测）**。  
- **禁止**：用复权价判板/成交；把 15 日铺满切日前样本；用主板 10% 套创业板/科创板整理期；整段整理期当无板；把整理期当「已退市=无行情」直接丢弃而不标窗口。

### 2.2 fail_policy（写死默认）

- 默认 **`fail_policy=skip`**：整理首日若引擎仍套板上买入约束、或成交日缺 OHLC/缺 exit 旗 → **跳过该腿**，不成交、不顺延填假价。  
- 允许拉数前改为 `defer` 等，**必须写入 params 并冻结**；**禁止跑后/看完净值再改口**。未写明则以 skip 为准。

### 2.3 三组对照（本实验编码）

| 组 | 整理期可交易性 | 涨跌停 / 买入约束 | 指数权重 |
|----|----------------|-------------------|----------|
| H0 天真-当普通日 | 可交易、可新开仓 | 用板块**默认**比例（含首日仍套 ±10%/±20%） | **仍计入**（或按普通成分保留） |
| H1 停牌化 | 不可新开仓；持仓收益记 0（横盘） | 不触发板上逻辑（当停牌） | 可按引擎默认；须声明 |
| H2 诚实-整理窗口 | 可交易（有量日）；可新开仓受诚实规则 | **首日不套**涨跌停买入约束；其后用**当时板块**限制；与 G/A 板上一致时叠 A 须声明 | **当日剔除** |

同一信号、同一 T+1、同一成本开关（本页可先零成本只比整理期处理差）。整手见 E；开/收时点见 D；无板 PIT 见 G——**勿把 A/D/E/G 主结论混进 H 主报告**；稳健性叠加须声明。

## 3. 样本区间

- **宇宙（默认）**：沪深 A 股股票中，样本期内出现过**退市整理**标记的标的（及同规则对照所需的非整理对照票可另桶）。不含可转债、不含股票 ETF 主样本。  
- **排除（默认）**：无法识别 `exit_start` / `delist_date`；整理窗口内全日无 OHLC 且无法与停牌旗区分却硬填；调仓日未上市。  
- **股票池 PIT**：每个调仓日只用当日已生效名单（可与实验 C 共用）；指数回测臂必须用当时成分 + 整理期当日剔除。  
- **区间建议**：待数据接入后锁定起止。建议复现默认（可改，须写入配置）：  
  - 主窗：覆盖 `params.exit_len_cut_date=2020-12-14` 前后足够样本（切日前 30 日窗 vs 切日后 15 日窗）；  
  - 稳健：创业板/科创板整理期子样本；整理首日无板子样本；与假设 G 无板表交叉核对首日标签。  
- **PIT 切片原则**：整理期长度、首日有无板、板块限制比例、是否进指数，一律按该交易日当时规则。

### 3.1 oos_split 占位（拉数前冻结；禁 holdout 反调）

配置占位字段（数值待锁，先占位）：

- `oos_split.is_start` / `oos_split.is_end`：样本内（IS）起止交易日  
- `oos_split.holdout_start` / `oos_split.holdout_end`：样本外 / holdout 起止  

**硬规则**：holdout / OOS 段**只用于一次性报告**；**禁止**用 holdout 反调整理期长度切日、三组定义、显著性阈值或任何事后标定。切分一经写入 params 即冻结，不得因 IS 结果改 holdout 边界。

## 4. 标签 / 对照设计

### 4.1 主对比

1. **H0 − H2**：当普通日（含首日误套板、指数仍计入）相对诚实整理窗口的净值差、失败笔数差、整理期贡献收益差。  
2. **H1 − H2**：停牌化（收益 0）相对诚实组——看是否抹掉整理期真实波动/可交易贡献。  
3. **分桶（须报）**：切日前（30 日规则）vs 切日后（15 日）；主板 vs 创业板/科创板；整理首日 vs 其后交易日；有指数权重臂 vs 纯选股臂。

### 4.2 成功 / 失败判据（相对）

主指标：

1. 净值差 ΔNAV（H0−H2、H1−H2）及整理期贡献切片；  
2. 失败笔数差 ΔFail（尤其首日误套板上导致的假受阻 / 假成交）；  
3. （可选）指数回测臂：整理期仍计入 vs 当日剔除的点位/收益差——**单列，不与选股臂混报主结论**。

**相对判据（草稿）**：若 |ΔNAV| **≥ Y** 或 |ΔFail| **≥ N** 或整理期贡献差 **≥ G**，记「整理期处理鸿沟显著」。

**Y / G / N / Y2（拉数前写入 params；禁 holdout 标定）**

| 符号 | 含义（占位） | 规则 |
|------|--------------|------|
| Y | 净值差显著门槛 | 拉数前写入 `params.Y` 并冻结 |
| G | 整理期贡献收益差门槛 | 拉数前写入 `params.G` 并冻结 |
| N | 失败笔数差门槛 | 拉数前写入 `params.N` 并冻结 |
| Y2 | 稳健子窗净值差门槛（可选） | 拉数前写入 `params.Y2` 并冻结 |
| exit_len_cut_date | 30→15 切日 | **写死默认** `params.exit_len_cut_date=2020-12-14`；拉数前冻结；禁事后改 |
| risk_warn_buy_cap_50w | 50 万股上限 | **写死默认 off**（不主测、不套整理股/科创） |

门槛可在 **IS 标定窗**（非 holdout）内事先约定噪声带后写入；**禁止用 holdout / OOS 段标定或反调**。Y/G/N/Y2 开工拉数前必须落进 params（可先占位后冻结）。

**失败/不显著**：差异落在噪声带内——结论栏写明，不得改口称「整理期处理无关」。

结论栏：空。跑完只写「该假设下差多少」，不写「这类整理期票能买/该规避名单」。

### 4.3 数值红线 v0 豁免（本机制实验）

本实验**只验退市整理期处理机制**（普通日 / 停牌化 / 诚实窗口），**不为组合策略放行实盘**。

- **显式豁免**：数值红线 v0（单票仓位、行业集中、回撤熔断等组合约束）**对本实验纸面/干跑豁免**——不因净值/IC 红线否决本机制对照。  
- **不豁免**：回测诚信（未复权、PIT 切日、禁 holdout 反调、禁荐股/禁当实盘预期）一律照做。  
- **不得沿用**：本豁免**不得**被组合策略或其他假设页拿去绕开红线 v0。

## 5. 预期失效条件

本假设或实验设定在下列情形下失效/须重切，不得硬套：

1. **15 日铺满切日前**：`exit_len_cut_date` 之前样本仍用 15 日（当时 30 日）。  
2. **首日误套板进诚实组**：H2 首日仍用 ±10%/±20% 买入约束（与口径/事实与坑及假设 G 冲突）。  
3. **整段整理期当无板**：首日之后仍不套板块限制。  
4. **主板 10% 套创业板/科创整理期**：其后限制未按板块当时规则。  
5. **50 万股上限默认套整理股/科创**：本页 `risk_warn_buy_cap_50w=off`；纳入须另开配置并核规则，禁止默开。  
6. **指数臂与选股臂混报**：整理期不进指数是指数规则；选股可交易性另计——混成一句「不能碰」属口径外延。  
7. **停牌计数错**：全天停牌仍推进 15/30 日计数；或把无量日 close=pre_close 当可交易却不标（与假设 D 交叉）。  
8. **宇宙泄露 / holdout 反调**：用今天名单倒填；看完 OOS 再改切日或三组定义。  
9. **与 A/G 混报主结论**：把「错标无板导致的假成交」算进「整理期处理差」却不声明。
