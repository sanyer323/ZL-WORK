## 1. 一句话假设（可检验、可证伪）

同一信号、同一未复权路径下，回测把 **A 股现金选择权行权过户费**误套成**股票二级成交金额档**（按成交金额 0.01‰、还往往按买卖双方），或把这笔过户记成 0，或因同是面值 0.5‰ 抄 DN 换股过户 / DQ 申赎篮子过户，或把权证/期权行权过户另立成主报，或与 U股票过户切日 / V股票印花切日 / T股票证管费 / DN换股过户 / DQ申赎篮子过户 / DU首日临停 / DT整手价位 / DS转股印花 / DR盘后通道 / R股票ETF假T+0 混读，或缺业务类型/官方‰/场所表仍不 skip，相对「缺业务类型/官方‰/场所表则 skip；现金选择权行权过户按行权股票过户面值 0.5‰ 单向；禁止套 A 股二级成交金额 0.01‰；禁止与 DN/DQ 仅因同数字合成一句」的诚实组，会**系统性改写现金选择权行权腿的过户成本**——相对诚实锚偏误。套成金额档，基数从面值变成成交金额，方向还可能从单向变成双边；抄 DN/DQ，业务对不上，数字碰巧相同也把成本写到别人的腿上。
