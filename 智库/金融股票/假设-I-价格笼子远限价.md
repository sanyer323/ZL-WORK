> 增量笔记。不荐股、不写买卖标的/仓位、不依赖聚宽真数、不跑回测结论。与 `口径.md` / `事实与坑.md` / `清单与配方.md` 实验 I 对齐。与假设 A（板上成交）、F（涨跌停价取整）、G（无板日 PIT）、L（市价保护限价，另页）互补：本页专测**连续竞价限价笼子**被当成「任意远限价都能进簿并按目标价成交」时，对废单率与成交偏离的扭曲。**日频无盘口时只做「远限价假设」敏感性，不假装精确复盘盘口。**

## 1. 一句话假设（可检验、可证伪）

同一信号、同一持有期、同一 T+1 下，把「次日开/收盘价总能按任意远离盘口的限价 100% 成交」当成市价式进簿，相对「每个交易日用当日已生效笼子文本（科创板开市起 2% 拒单；创业板 2020-08-24～2023-04-09：2% 存单；2023-04-10 起沪深主板+创业板：2% 与 ±0.1 元孰宽、拒单；科创板一直无十个价位）」的诚实 PIT 组，**废单率与实际成交价相对盘口/基准的偏离会显著升高（或在泄露组被系统性错切）**；主板 2023-04-10 前若按现行笼子拒单，会把当时能进簿的远单算成失败。

证伪方向：若天真组 / 泄露组相对 PIT 组的废单率差、成交偏离差、净值差在标定噪声带内可忽略，且切日前/存单期分桶不改变结论，则本假设在该样本与撮合设定下不成立。

## 2. 可编码概念 / 定义

### 2.1 价格笼子（连续竞价限价；按成交日当时规则）

```
# 配置写死（见 §7）
# params.asof_check_date           写死默认 2026-10-12（事实与坑核对日）
# params.cage_chinext_start        写死默认 2020-08-24
# params.cage_main_cut_date        写死默认 2023-04-10（首只注册制主板上市日；非印发日 2023-02-17）
# params.ten_tick_star             写死默认 off（科创板无十个价位）
# params.day_freq_mode             写死默认 far_limit_sensitivity
# params.baseline_source_dayfreq   写死默认 last_or_open_proxy
#   （真盘口优先：bid1/ask1→对侧→最新成交→前收盘；日频无盘口不得用「仅前收盘×1.02」当唯一基准）
# 拉数前冻结；禁 holdout / 事后改切日或基准定义

tick = 0.01  # A 股股票默认；基金/ETF 勿混入本页主样本

def cage_rule(board, asof_date):
    # 返回 (pct, ten_tick, overflow_mode)
    # overflow_mode ∈ {reject, store, none}
    if board == "STAR":  # 科创板：开市起
        return (0.02, False, "reject")
    if board == "ChiNext":
        if asof_date < params.cage_chinext_start:
            return (None, False, "none")  # 当时无本页所述 2% 连续竞价笼子
        if asof_date < params.cage_main_cut_date:
            return (0.02, False, "store")  # 超范围暂存主机，非当场拒单
        return (0.02, True, "reject")      # 2% 与 ±10 tick 孰宽；拒单
    if board in ("Main", "SH_Main", "SZ_Main"):
        if asof_date < params.cage_main_cut_date:
            return (None, False, "none")   # 此前主板连续竞价无此套笼子
        return (0.02, True, "reject")
    return (None, False, "none")

def cage_band(baseline, pct, ten_tick, side):
    # side: buy → upper bound; sell → lower bound
    # 现行表述：买不得高于 max(baseline*1.02, baseline+10*tick)；卖对称
    if pct is None:
        return None
    pct_bound = baseline * (1 + pct) if side == "buy" else baseline * (1 - pct)
    if ten_tick:
        tick_bound = baseline + 10 * tick if side == "buy" else baseline - 10 * tick
        # 「孰宽」：买方取更高上界；卖方取更低下界
        return max(pct_bound, tick_bound) if side == "buy" else min(pct_bound, tick_bound)
    return pct_bound
```

- **基准价**：优先即时揭示的对手方一档（买看卖一、卖看买一），再对侧，再最新成交，再前收盘。**禁止**默认只用「前收盘 × 1.02」。  
- **日频最小集**（`day_freq_mode=far_limit_sensitivity`）：无买卖一时，用未复权最新价/开盘价作**粗糙代理基准**，只报告「限价相对代理基准偏离 ≥ `far_limit_mult` 档」的敏感性与废单/存单标记差；**禁止**输出「精确盘口复盘」声称。  
- **与涨跌停分离**：笼子管「能挂多远」；板上见假设 A/F。超涨跌幅/有效申报范围本身拒单，不并进本页主结论却不声明。  
- **不适用时段**：开市期间临时停牌阶段的连续竞价笼子两款不适用（事实与坑）；集合竞价另有范围——本页**不主测**集合竞价/临停申报范围（见实验 J）。  
- **禁止**：科创板套十个价位；主板切日前按现行拒单；创业板存单期把超范围写成废单；把笼子差异写成「这类票能买」。

### 2.2 fail_policy（写死默认）

- 默认 **`fail_policy=skip`**：缺基准代理、缺板块/切日、或笼子规则表无法判定 → **跳过该腿**，不成交、不顺延填假价。  
- 存单期（`overflow_mode=store`）：超范围**不记废单**；记「待价格走回才可能成交」；日频无法模拟走回时 → **按 skip 不记成交**（不得记 100% 成交，也不得记 reject）。  
- 允许拉数前改为 `defer` 等，**必须写入 params 并冻结**；**禁止跑后/看完净值再改口**。未写明则以 skip 为准。

### 2.3 三组对照（本实验编码）

| 组 | 限价进簿假设 | 笼子文本 | 超范围 |
|----|--------------|----------|--------|
| I0 天真-远限价总能成 | 次日开/收盘价 100% 成交；限价可远离盘口 | 无笼子约束 | 不废、不存 |
| I1 泄露-现行铺满 | 受笼子约束 | **全样本**用核对日现行：2% + 十个价位（主板/创业）拒单；科创仍无十价位 | 超范围=拒单 |
| I2 诚实-PIT | 受笼子约束 | **每个交易日**用当日已生效文本（切日/存单/无笼分段） | reject / store / none 按 §2.1 |

同一信号、同一 T+1、同一成本开关（本页可先零成本只比笼子处理差）。成交时点默认与假设 A/D 声明一致（建议次日开；若用收须单列）。整手见 E；板上见 A；市价通道见 L——**勿把 A/D/E/L 主结论混进 I 主报告**；稳健性叠加须声明。

**远限价敏感性档（日频）**：事先写死 `params.far_limit_mult`（默认建议 `[1.0, 1.02, 1.05, 1.10]` 相对代理基准；拉数前冻结）。I0 在所有档都当成可成；I1/I2 按笼子上/下界裁切或标废/存。

## 3. 样本区间

- **宇宙（默认）**：沪深 A 股股票（主板 / 创业板 / 科创板）。不含可转债、不含股票 ETF 主样本。  
- **排除（默认）**：调仓日未上市；无法识别板块；无涨跌幅日的集合竞价/临停窗（本页不主测，见 J）；成交日缺 OHLC；日频无法构造任何基准代理却硬用前收盘×1.02 单基准。  
- **股票池 PIT**：每个调仓日只用当日已生效名单（可与实验 C 共用）。  
- **区间建议**：待数据接入后锁定起止。建议复现默认（可改，须写入配置）：  
  - 主窗：覆盖 `params.cage_chinext_start=2020-08-24` 与 `params.cage_main_cut_date=2023-04-10` 前后足够样本；  
  - 稳健分桶：主板切日前 / 创业板存单期 / 科创板低价股（十价位是否误套） / 切日后拒单期。  
- **PIT 切片原则**：笼子比例、有无十个价位、overflow 是拒单还是存单、主板有无笼，一律按该交易日当时规则。

## 4. 标签 / 对照设计

### 4.1 主对比

1. **I0 − I2**：远限价总能成相对 PIT 笼子——废单率差、成交偏离差、净值差。  
2. **I1 − I2**：现行铺满相对 PIT——看切日前主板/存单期是否被系统性错标成拒单。  
3. **分桶（须报）**：主板 `<2023-04-10`；创业板存单期 `[2020-08-24, 2023-04-10)`；科创板；切日后拒单期；低价股（十价位孰宽是否敏感）。

### 4.2 成功 / 失败判据（相对）

主指标：

1. 废单率差 ΔReject（及存单期「未成交但非废单」计数，须与 reject 分列）；  
2. 成交价相对代理基准/盘口的偏离差 ΔDev；  
3. 净值差 ΔNAV（I0−I2、I1−I2）——**可选**，有信号臂时才报，不得单独当「能买」证据。

**相对判据（草稿）**：若 |ΔReject| **≥ N** 或 |ΔDev| **≥ D** 或 |ΔNAV| **≥ Y**，记「笼子/远限价鸿沟显著」。

**Y / D / N / Y2（拉数前写入 params；禁 holdout 标定）**

| 符号 | 含义（占位） | 规则 |
|------|--------------|------|
| Y | 净值差显著门槛 | 拉数前写入 `params.Y` 并冻结 |
| D | 成交偏离差门槛 | 拉数前写入 `params.D` 并冻结 |
| N | 废单率/笔数差门槛 | 拉数前写入 `params.N` 并冻结 |
| Y2 | 稳健子窗净值差门槛（可选） | 拉数前写入 `params.Y2` 并冻结 |
| asof_check_date | 泄露组「现行」核对日 | **写死默认** `params.asof_check_date=2026-10-12`；拉数前冻结 |
| cage_chinext_start | 创业板笼子起点 | **写死默认** `2020-08-24` |
| cage_main_cut_date | 主板+创业板拒单/十价位 | **写死默认** `2023-04-10` |
| ten_tick_star | 科创十价位 | **写死默认 off** |
| day_freq_mode | 日频模式 | **写死默认** `far_limit_sensitivity` |
| far_limit_mult | 远限价敏感性倍率列表 | 拉数前写入 params 冻结；禁事后改档 |

门槛可在 **IS 标定窗**（非 holdout）内事先约定噪声带后写入；**禁止用 holdout / OOS 段标定或反调**。Y/D/N/Y2 开工拉数前必须落进 params（可先占位后冻结）。

**失败/不显著**：差异落在噪声带内——结论栏写明，不得改口称「笼子无关」。

结论栏：空。跑完只写「该假设下差多少」，不写「这类票因笼子能买/该规避」。

## 5. 预期失效条件

本假设或实验设定在下列情形下失效/须重切，不得硬套：

1. **前收盘×1.02 当唯一基准**：与事实与坑明确冲突；日频代理须声明 `last_or_open_proxy`，不得伪装成买卖一。  
2. **科创板套十个价位**：`ten_tick_star` 必须为 off。  
3. **主板 `<2023-04-10` 按现行拒单进诚实组**：I2 该段应为 `overflow_mode=none`。  
4. **创业板存单期写成废单**：I2 超范围=store，不得记 reject；日频走不回则 skip 不成交。  
5. **把笼子和涨跌停混成一句**：板上逻辑属 A/F；本页只报进簿/废单/偏离。  
6. **无盘口却报「精确复盘」**：违反 `day_freq_mode=far_limit_sensitivity`。  
7. **与实验 L（市价）混表不标注通道**：限价笼子 ≠ 市价保护限价。  
8. **宇宙泄露 / holdout 反调**：用今天规则铺满却当 PIT；看完 OOS 再改切日或 `far_limit_mult`。  
9. **集合竞价/临停范围并进主结论不声明**：见实验 J；本页默认排除。
