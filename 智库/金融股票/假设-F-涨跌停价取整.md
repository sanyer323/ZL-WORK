## 1. 一句话假设（可检验、可证伪）

同一日、同一未复权收盘价与交易所前收盘/除权参考价下，用 `前收盘 × (1±比例)` 的**未取整小数**去标涨跌停，相对「四舍五入到最小价位（默认 0.01）；差不到 1 个价位则前收盘加减 1 个价位」的诚实板上价，**标签会系统性翻车**；差异率应集中在**低价股分桶与除权（息）日**，而不是随机散开。错标会把后续「假成交 / 板上约束」实验（如假设 A）带偏。

证伪方向：若未取整组相对取整组的标签差异率在标定噪声带内可忽略，或差异不集中在低价/除权桶而呈均匀噪声，则本假设在该样本与取整设定下不成立。

## 2. 可编码概念 / 定义

### 2.1 涨跌停价两套算法（未复权；按成交日当时比例）

```
# 配置写死（见 §7）
tick = 0.01                         # 仅沪深 A 股股票；禁基金/可转债 0.001
limit_pct_source = board_st_day_effective   # 主板/创业/科创/ST 按日生效；含主板 ST 2026-07-06 5%→10%
pct  = limit_pct(i, t)              # 由 limit_pct_source 切片；无涨跌幅日本页不标板

raw_up   = pre_close * (1 + pct)
raw_down = pre_close * (1 - pct)

# F0 天真-未取整：直接用 raw 与 close 比
is_up_naive   = (close >= raw_up)
is_down_naive = (close <= raw_down)

# F1 诚实-取整到 tick（交易所常见：先乘比例再四舍五入到分）
def round_half_up(x, tick):
    return floor(x / tick + 0.5) * tick

limit_up   = round_half_up(raw_up, tick)
limit_down = round_half_up(raw_down, tick)
# 差不到 1 个价位：|limit - pre_close| < tick → limit = pre_close ± tick
if abs(limit_up - pre_close) < tick:   limit_up = pre_close + tick
if abs(limit_down - pre_close) < tick: limit_down = pre_close - tick
if limit_up < tick:   limit_up = tick
if limit_down < tick: limit_down = tick

# 标签比较符写死（默认）：>= / <=（与假设 A 板上判定一致）
is_up_honest   = (close >= limit_up)
is_down_honest = (close <= limit_down)
```

#### 标签比较符写死 + 与假设 A 对齐声明

| 项 | 写死值 |
|----|--------|
| **默认比较符** | **`>=` / `<=`**：`is_up = (close >= limit_or_raw_up)`；`is_down = (close <= limit_or_raw_down)` |
| **非默认（本页不用）** | `==`（先把 `close` 与板上价都四舍五入到同一 `tick` 再比相等）——**本页默认关闭**；不得事后改成 `==` 解读差异率 |
| **与假设 A** | 假设 A §2.1：`is_limit_up_close = (close >= limit_up)` / `is_limit_down_close = (close <= limit_down)`。**本页 F1 与 A 板上判定一致**（同 `>=`/`<=`、同 `round_half_up`+不足一档补一档）。叠 A 时板上价来源必须为 F1，标签比较符不得另切。 |
| **有意边界** | F0 用未取整 `raw_*` 做同一 `>=`/`<=` 是本实验对照臂，**不是** A 的诚实板上标签；A 禁止用未取整 raw 判板。除权参考价、未复权、`limit_pct_source` 与 A 同向。 |

- **前收盘**：除权/息日用交易所**除权参考价**（见罐内事实与坑），禁止用数据商复权前收盘。  
- **tick 范围（写死）**：`tick=0.01` **仅**沪深 A 股股票主样本；**禁止**基金 / ETF / 可转债 `0.001` tick 混进本页。交易所若另有**股价分档 tick** 表：**未核验到现行表则本页不按分档切片**（一律 0.01）；**禁止事后用分档表反打已跑标签**（不得用结果回头改 tick/分档）。  
- **禁止**：用复权价做任一对照；把未取整 `raw_*` 当成交易所挂牌涨跌停价；无涨跌幅日硬套 ±10%/±20%；跑后改比较符或 tick。

### 2.2 对照组（本实验编码）

| 组 | 板上价 | 标签规则 |
|----|--------|----------|
| F0 天真-未取整 | `raw_up/raw_down` | close 与未取整小数直接比较 |
| F1 诚实-取整 | `limit_up/limit_down`（round + 不足一档补一档） | close 与取整后板上价比较 |
| F2 误切-复权判板（反例） | 用前复权/后复权收盘与复权前收盘套同一比例 | **仅作反例**；差异应与除权日重叠，不得当主结论 |

同一日、同一 `pct` 切片、同一股票宇宙。本页**主测标签差异**，不主测成交撮合（成交见 A/D；整手见 E）。若叠 A1，须声明「板上价来源=F1」，禁止用 F0 板上价跑 A 却声称诚实。

### 2.3 fail_policy（写死默认）

本实验以**日截面标签对照**为主，无「意图单失败顺延」主路径。配置仍写死：

- 默认 **`fail_policy=skip`**：无 `pre_close`/无法算 `pct`/无涨跌幅日 → **跳过该日该票标签**，不填假板、不顺延用邻日规则。  
- 允许拉数前改为其他剔除策略，**必须写入 params 并冻结**；**禁止跑后/看完差异率再改口**。未写明则以 skip 为准。

## 3. 样本区间

- **宇宙（默认）**：沪深 A 股股票（不含可转债、不含股票 ETF 主样本）。须含足量**低价股**与**除权（息）日**，否则分桶不可检。  
- **排除（默认）**：无涨跌幅日（见实验 G；纳入须另标）；调仓/样本日未上市；退市整理期（见实验 H）；`pre_close` 或未复权 close 缺失；无法识别板块/`pct`。  
- **股票池 PIT**：每个交易日只用当日已生效可交易名单（勿用核对日还上市的全 A；可与实验 C 共用名单表）。  
- **区间建议**：待数据接入后锁定起止。建议复现默认（可改，须写入配置）：  
  - 主窗：最近完整 5 个自然年交易日；  
  - 稳健：主板 ST 5%→10% 切日（2026-07-06）前后；创业板 20% 落地后；除权密集季。  
- **PIT 切片原则**：限制比例、ST 档、有无涨跌幅、最小价位，一律按该交易日当时规则。

### 3.1 oos_split 占位（拉数前冻结；禁 holdout 反调）

配置占位字段（数值待锁，先占位）：

- `oos_split.is_start` / `oos_split.is_end`：样本内（IS）起止交易日  
- `oos_split.holdout_start` / `oos_split.holdout_end`：样本外 / holdout 起止  

**硬规则**：holdout / OOS 段**只用于一次性报告**；**禁止**用 holdout 反调取整规则、分桶边界、显著性阈值或任何事后标定。切分一经写入 params 即冻结，不得因 IS 结果改 holdout 边界。

## 4. 标签 / 对照设计

### 4.1 主对比

1. **F0 vs F1**：未取整 vs 取整的涨停/跌停标签差异率（全日、涨停子集、跌停子集）。  
2. **分桶**：`params.price_buckets` **写死默认** `[0,5,20,inf]`（元，未复权收盘；桶为左闭右开至最后开：`[0,5)` / `[5,20)` / `[20,inf)`）；**拉数前冻结**；**禁止 holdout 标定 / 事后改桶边**再解读「低价集中」。另报**除权（息）日** vs 非除权日。  
3. **F2 − F1**（可选反例）：复权判板相对诚实取整的差异；应与除权日高度重叠。

### 4.2 成功 / 失败判据（相对）

主指标：

1. 标签差异率 δ = 日×票上 `(is_up_naive != is_up_honest) or (is_down_naive != is_down_honest)` 的占比；  
2. 低价桶 δ_low vs 高价桶 δ_high；除权日 δ_ex vs 非除权 δ_nex；  
3. （可选）若叠 A：用 F0 板上价跑 A1 vs 用 F1 板上价跑 A1 的受阻笔数/净值差——**单列稳健性，不进 F 主结论**。

**相对判据（草稿）**：若总体 δ **≥ D**，或 δ_low − δ_high **≥ D_gap**，或 δ_ex − δ_nex **≥ D_ex**，记「取整鸿沟显著」。

**D / D_gap / D_ex（拉数前写入 params；禁 holdout 标定）**

| 符号 | 含义（占位） | 规则 |
|------|--------------|------|
| D | 总体标签差异率显著门槛 | 拉数前写入 `params.D` 并冻结 |
| D_gap | 低价桶相对高价桶差异率差门槛 | 拉数前写入 `params.D_gap` 并冻结 |
| D_ex | 除权日相对非除权差异率差门槛 | 拉数前写入 `params.D_ex` 并冻结 |
| price_buckets | 股价分桶边界 | **写死默认** `params.price_buckets=[0,5,20,inf]`；拉数前冻结；**禁 holdout 标定 / 事后改桶** |

门槛 D/D_gap/D_ex 可在 **IS 标定窗**（非 holdout）内事先约定噪声带后写入；**禁止用 holdout / OOS 段标定或反调**。**`price_buckets` 已写死默认 `[0,5,20,inf]`**，拉数前冻结，不得因 IS/holdout 结果改桶。D* 开工拉数前必须落进 params（可先占位后冻结）。

**失败/不显著**：δ 落在噪声带内，或差异均匀散开而非低价/除权集中——结论栏写明，不得改口称「取整无关」。

结论栏：空。跑完只写「该假设下差多少」，不写「这类低价股能买」。

## 5. 预期失效条件

本假设或实验设定在下列情形下失效/须重切，不得硬套：

1. **复权判板混进主结论**：F2 仅反例；主报告必须是未复权 F0 vs F1。  
2. **除权日用错前收盘**：用数据商复权前收盘而非交易所除权参考价。  
3. **无涨跌幅日硬套板**：IPO 前 5 日/整理首日等仍标 ±10%/±20%（见实验 G）。  
4. **规则切日未切片**：用现行 ST 档或创业板 20% 铺满历史。  
5. **tick 错位 / 事后反打**：用基金/债券 `0.001` 最小价位；或把港股/北交所价位抄进沪深 A 股主样本；或分档 tick 未核验却切片；或用跑后结果回头改 tick/分档。  
6. **与 A 混报主结论**：把「错标导致的假成交差」算进「取整标签差」却不声明。  
7. **宇宙泄露**：用今天还上市的票回放；低价/除权样本过少却宣称无差异。  
8. **holdout 反调**：看完 OOS 差异后再改 round 模式或分桶。
