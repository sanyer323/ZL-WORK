# 口径

> 领域：金融股票。增量追加，勿整篇清空。

## 主人视角（2026-09-18）

- 先谈 **中短线买卖**，暂不展开长期投资。
- 重视 **人性**（贪、怕、跟风、拥挤、对手盘）；价格可长期偏离「价值」。
- 「公司好 ≠ 现价值得买」（例：质地好也可能觉得贵）。
- 量化多了 → 对手主要是别的量化 → 比谁更强；同质化后超额变难。
- DeepSeek 有幻方血统 ≠ 自带幻方实盘策略。
- 不在此库做具体荐股；讨论机制与人性即可。

## 主人目标纠偏（2026-09-19）

- **总目标**：为以后**自己做量化操作**打基础——让智库自己变厚，而不是养成「盯盘荐股助手」。
- 人性/拥挤/对手盘仍要写，但用途改为：**理解市场微观结构与可编码信号**，不是手盘跟单话术。
- Automation / 对话喂养时，金融日优先补这几类（可复用、可落地）：
  1. **数据与口径**：复权、停牌、涨跌停、T+1、费用与滑点怎么进回测  
  2. **因子与特征**：怎么定义、怎么防偷看未来、怎么做截面/时序检验  
  3. **组合与风控**：仓位、回撤、拥挤度、同质化失效  
  4. **执行与仿真**：撮合假设、涨跌停摸不到、实盘与回测鸿沟  
  5. **工程骨架**：研究笔记 → 可复现实验 →（以后）策略代码；本阶段以知识与清单为主
- **仍禁止**：具体买卖标的、仓位指令、代操实盘；未经验证的「必胜公式」。
- 阶段边界：现在 = **学与建罐**；有了稳定口径与清单后再谈写回测/实盘代码。
