# 假设 J · 无涨跌幅日把最高价当连续可成交（盘中临停）

更新：2026-11-02  
来源：总管催办 / H 复检·I 等预检期间下一可离线纸面；清单实验 J  
状态：**草稿 · 待数据 · 待跑**（结论栏空；禁止把「无板日最高/最低总能连续成交」当实盘预期；不抢实验 A 真数队列）

> 增量笔记。不荐股、不写买卖标的/仓位、不依赖聚宽真数、不跑回测结论。与 `口径.md` / `事实与坑.md` / `清单与配方.md` 实验 J 对齐。与假设 G（无涨跌幅日 PIT）、I（价格笼子/远限价）、A（板上成交）、H（退市整理首日无板）互补：本页专测**无涨跌幅日盘中临停**被当成「全日连续可按最高/最低成交」时，对可交易路径与极值贡献收益的扭曲。**比较基准写死为当日开盘价，禁止对前收盘/发行价。**

---

## 1. 一句话假设（可检验、可证伪）

同一信号、同一持有期、同一 T+1 下，在新股前 5 日 / 退市整理首日 / 重新上市首日等无涨跌幅日，把「当日最高/最低价可连续撮合」当成可成交路径，相对「较当日开盘价触及 30%/60% 的时段记临时不可连续撮合（有公告用公告；无公告至少不要用穿过阈值后的极值当默认成交价）」的诚实组，**失败笔数与极值贡献的那截收益会显著升高**；再把现行 30%/60% 套到注册制前主板新股首日（误切组），会进一步错标临停窗。

证伪方向：若天真组 / 误切组相对诚实组的失败笔数差、极值贡献差、净值差在标定噪声带内可忽略，且「对开盘价 vs 对前收盘」分桶不改变结论，则本假设在该样本与撮合设定下不成立。

## 2. 可编码概念 / 定义

### 2.1 无板日盘中临停（按成交日当时规则；未复权）

```
# 配置写死（见 §7）
# params.asof_check_date           写死默认 2026-10-12（事实与坑核对日）
# params.halt_pct_1                写死默认 0.30
# params.halt_pct_2                写死默认 0.60
# params.halt_minutes              写死默认 10
# params.halt_baseline             写死默认 open   # 禁止 pre_close / issue_price
# params.halt_chinext_start        写死默认 2020-08-24
# params.halt_main_cut_date        写死默认 2023-04-10  # 主板复制 30%/60% 与新股前5日无板同日；非印发日
# params.max_halts_per_direction   写死默认 1   # 同向直接冲过60%只停一次；涨跌两向最多四次
# params.star_legacy_10_20         写死默认 off # 本页主测现行30%/60%；科创早期10%/20%不主测
# 拉数前冻结；禁 holdout / 事后改阈值或基准

tick = 0.01  # A 股股票默认；基金/ETF/可转债勿混入本页主样本

def is_no_limit_day(i, t, no_limit_table):
    # 复用假设 G 的 PIT 无板表：IPO 前5日 / 退市整理首日 / 重新上市首日 等
    return no_limit_table.get((i, t), False)

def halt_rule_applies(board, asof_date):
    # 现行 30%/60% 临停是否已落地到该板块
    if board == "STAR":
        return True  # 科创板开市起（现行档；早期10/20不主测）
    if board == "ChiNext":
        return asof_date >= params.halt_chinext_start
    if board in ("Main", "SH_Main", "SZ_Main"):
        return asof_date >= params.halt_main_cut_date
    return False

def intraday_halt_bands(open_px):
    # 基准 = 当日开盘价（交易所定义）；禁止前收盘/发行价
    if open_px is None or open_px <= 0:
        return None
    up1   = open_px * (1 + params.halt_pct_1)
    down1 = open_px * (1 - params.halt_pct_1)
    up2   = open_px * (1 + params.halt_pct_2)
    down2 = open_px * (1 - params.halt_pct_2)
    return (up1, down1, up2, down2)

def crosses_halt(high, low, bands):
    # 日频占位：若 high/low 穿过阈值，标记「曾触发临停窗」；不假装精确还原 10 分钟时段
    if bands is None:
        return False
    up1, down1, up2, down2 = bands
    return (high >= up1) or (low <= down1) or (high >= up2) or (low <= down2)
```

- **适用日**：仅 `is_no_limit_day=True` 且 `halt_rule_applies` 的交易日。有涨跌幅限制日的板上逻辑见 A/F；本页不主测。  
- **比较基准写死**：`params.halt_baseline=open`。开盘价按交易所定义（集合竞价第一笔；走不成再连续竞价）。**禁止**对前收盘/发行价算 30%/60%。  
- **时长与次数**：单次 **10 分钟**；同向直接冲过 60% 只停一次；涨、跌两向最多四次。停牌期间可申报也可撤单；复牌集合竞价；跨越 14:57 且须当日复牌的于 14:57 复牌——日频最小集**不精确复盘申报簿**，只禁止把穿过阈值后的极值当默认连续成交价。  
- **日频最小集**：无分钟线/无临停公告时，诚实组对「`crosses_halt=True`」的成交腿：**不得**用当日 high（买）/ low（卖）作为默认成交价；改用开盘价、或记 skip/部分失败（须事先写死 `params.j2_fill_when_cross`）。有公告时段则优先公告窗内记临时不可连续撮合。  
- **禁止**：用复权价；临停比例对开盘价改成对前收盘/发行价；把 10 分钟临停写成全日不可交易；把可转债首日临停（较发行价 20%/30%）并进本页主结论；结论写成「这类次新能买」。

### 2.2 fail_policy（写死默认）

- 默认 **`fail_policy=skip`**：缺开盘价、缺无板旗、无法判定 `halt_rule_applies`、或穿过阈值却无事先写死的替代成交假设 → **跳过该腿**，不成交、不顺延用 high/low 填假连续路径。  
- 允许拉数前改为 `defer` 等，**必须写入 params 并冻结**；**禁止跑后/看完净值再改口**。未写明则以 skip 为准。

### 2.3 三组对照（本实验编码）

| 组 | 无板日成交假设 | 临停文本 | 穿过 30%/60% 后 |
|----|----------------|----------|-----------------|
| J0 天真-极值连续可成 | 按当日最高买 / 最低卖（或信号目标价夹在 high-low 内即成） | 无临停约束 | 仍 100% 连续可成 |
| J1 诚实-开盘价临停 | 受临停约束 | **每个交易日**用当日已生效文本（板块切日 + 开盘价基准） | 临时不可连续撮合；日频默认不用穿过后极值当成交价（见 `j2_fill_when_cross`） |
| J2 误切-注册制前也套 | 受临停约束 | **全样本**（含主板 `<2023-04-10` 新股首日等）用现行 30%/60% | 同 J1 处理，但切日前本不该套的也被套 |

同一信号、同一 T+1、同一成本开关（本页可先零成本只比临停处理差）。成交时点默认与假设 A/D 声明一致（建议次日开；若用收须单列）。无板日判定见 G；笼子见 I；整理首日无板见 H——**勿把 A/D/G/H/I 主结论混进 J 主报告**；稳健性叠加须声明。

**`params.j2_fill_when_cross`（拉数前写死；建议默认 `skip_or_open`）**：日频检测到穿过阈值后的成交价假设——`skip`（该腿失败）或 `open`（改用开盘价）或 `announce_window`（有公告才精细）。**禁止**默认 `high_low`。本页建议默认 **`skip_or_open`**（无公告→skip；有开盘→可回退 open；禁 high/low）。

## 3. 样本区间

- **宇宙（默认）**：沪深 A 股股票中，样本期内出现过**无涨跌幅日**的标的（IPO 前 5 日 / 退市整理首日 / 重新上市首日等；无板表可与假设 G 共用）。不含可转债、不含股票 ETF 主样本。  
- **排除（默认）**：调仓日未上市；有涨跌幅限制日（本页不主测板上）；成交日缺 open/high/low；无法识别板块/无板旗却硬套 30%/60%；可转债首日临停样本（另案）。  
- **股票池 PIT**：每个调仓日只用当日已生效名单（可与实验 C 共用）。  
- **区间建议**：待数据接入后锁定起止。建议复现默认（可改，须写入配置）：  
  - 主窗：覆盖 `params.halt_chinext_start=2020-08-24` 与 `params.halt_main_cut_date=2023-04-10` 前后足够无板日样本；  
  - 稳健分桶：主板切日前新股首日（J2 误切敏感） / 创业板注册制后前 5 日 / 科创板 / 整理首日 / 重新上市首日 / 对开盘价 vs 误对前收盘（诊断桶，诚实组不得用后者）。  
- **PIT 切片原则**：有无临停、阈值比例、基准是否开盘价、板块是否已落地，一律按该交易日当时规则。

### 4.2 成功 / 失败判据（相对）

主指标：

1. 失败笔数差 ΔFail（临停窗导致 skip / 不可连续撮合）；  
2. 极值贡献收益差 ΔExt（J0 用 high/low 多吃到的那截）；

## 5. 预期失效条件

本假设或实验设定在下列情形下失效/须重切，不得硬套：

1. **对前收盘/发行价算 30%/60%**：与事实与坑明确冲突；`halt_baseline` 必须为 `open`。  
2. **主板 `<2023-04-10` 新股首日进诚实组却套现行临停**：J1 该段 `halt_rule_applies=False`；套了的是 J2。  
3. **把 10 分钟临停写成全日不可交易**：诚实组只挡「穿过后的连续撮合极值」，不是整日停牌化（整日停牌见 D）。  
4. **用复权 high/low**：一律未复权。  
5. **无板表泄露 / 与 G 不一致**：无板日判定须与假设 G PIT 表同向；不得用核对日现行「前 5 日无板」铺满注册制前。  
6. **可转债首日临停并进主结论**：转债是较发行价 20%/30%、时长不同——禁止混表不声明。  
7. **日频却报「精确 10 分钟复盘」**：无分钟/无公告时只允许 skip_or_open 敏感性。  
8. **宇宙泄露 / holdout 反调**：看完 OOS 再改切日、阈值或 `j2_fill_when_cross`。  
9. **与 I（笼子）/A（板上）混报主结论**：笼子管限价能挂多远；板上管有涨跌幅日；本页只管无板日临停路径。
