## 1. 一句话假设（可检验、可证伪）

同一选股规则、同一持有期、同一 T+1、同一成交时点下，把「按任意股数 / 任意金额精确成交」改成按当时板块整手约束（主板/创业板买入向下取整到 100 股整数倍、零股仅清仓一次性卖出；科创板买入单笔至少 200 股且限价/市价上限按当时规则切、余额不足 200 股一次性卖）后，**小账户与科创板实际仓位会更粗、计划换手下降、废单/跳过笔数上升**；若把创业板误写成 200 股起，废单与仓位偏离会进一步放大。科创板子集与小名义资金档偏离更大。

证伪方向：若诚实整手组相对天真任意股数组的仓位粒度差、废单笔数差与换手差在标定噪声带内可忽略，且科创板并不比主板/创业板多掉一截，则本假设在该样本与撮合设定下不成立。

## 2. 可编码概念 / 定义

### 2.1 板块整手规则（按成交日当时规则切片）

伪代码级（不编造历史真数；默认对齐事实与坑 2026-10-05 核对口径）：

```
# board ∈ {main, chinext, star}  # 主板 / 创业板 / 科创板；按日 PIT
# side ∈ {buy, sell}; qty_intent = 意图股数（可来自金额/权重换算）

lot_main_chinext = 100          # 主板、创业板：100 股整数倍
lot_star_min_buy = 200          # 科创板：买入单笔 ≥200
star_limit_max   = 100_000      # 科创限价单笔上限（股）
star_market_max  = 50_000       # 科创市价单笔上限（股）
# 盘后收盘定价科创：200～1_000_000；本页默认关闭盘后通道（见实验 M）

def round_buy(board, qty, order_type="limit"):
    if board in ("main", "chinext"):
        return floor(qty / 100) * 100          # 禁止写成创业板 200 起
    if board == "star":
        q = floor(qty)                         # 仍须 ≥200；不足则本笔失败或跳过
        if q < 200: return 0
        cap = star_limit_max if order_type=="limit" else star_market_max
        return min(q, cap)                     # 超额须拆单规则事先写死；本页默认截断到上限并计「截断」
    raise UnknownBoard

def round_sell(board, qty_held, is_flat_exit):
    # 零股：余额不足一手（主板/创业板 <100；科创 <200）只允许一次性卖出，禁止拆成多笔
    if board in ("main", "chinext"):
        if qty_held < 100:
            return qty_held if is_flat_exit or True else 0   # 默认：不足一手只能整笔卖
        return floor(qty_held / 100) * 100 if not is_flat_exit else qty_held
    if board == "star":
        if qty_held < 200:
            return qty_held                    # 一次性卖出
        return qty_held if is_flat_exit else floor(qty_held / 1)  # 科创卖出无「100 倍」硬套；主测清仓零股门槛
```

- **禁止**：把创业板写成 200 股起；把送转后零股拆成多笔卖；用股票 100 股规则套 ETF/可转债（另见实验 Q/R）。
- **fail_policy（写死默认）**：本实验配置默认 **`fail_policy=skip`**（整手截断后 qty=0、或科创买不足 200、或超单笔上限且未声明拆单 → 该腿失败/跳过，不顺延）；允许拉数前改为 `defer`，**必须写入 params 并冻结**；**禁止跑后/看完净值再改口**。未写明则以 skip 为准。
- 成交价默认与假设 A/D 对齐建议：`fill_default=next_open`（本页不主测开/收；三组同开同关）。涨停板上硬约束默认 **off**（稳健性可叠 A1 并声明）。

### 2.2 三组撮合（本实验编码）

| 组 | 买入股数 | 卖出 / 零股 | 科创上限 |
|----|----------|-------------|----------|
| E0 天真-任意股数 | 按意图金额/权重精确到股（可碎股） | 可任意拆卖 | 不切 |
| E1 诚实-主板创业 100 + 科创 200 | 主板/创业向下取整 100；科创买 ≥200 否则 0 | 不足一手（100/200）一次性卖；禁止拆零股多笔 | 限价≤10万 / 市价≤5万（截断或按事先拆单） |
| E2 误套-创业板当 200 | 同 E1，但**创业板也按 200 起**（反例组） | 同 E1 对创业板误用 200 零股门槛 | 同 E1 |

同一信号、同一 T+1、同一成交时点、同一成本开关（本页可先零成本只比整手差；成本见 S/T，板上见 A，开收/停牌见 D——**勿把 A/D 差分混进 E 主结论**）。

### 2.3 名义资金分档（须报）

为显式暴露「小账户被吹胖」：配置占位 `notional_buckets`（例：10万 / 50万 / 200万人民币可交易资金），每档同一信号权重；主报告至少含一档「小」与一档「中」。数值待锁，拉数前写入 params。

## 3. 样本区间

- **宇宙（默认）**：沪深 A 股股票（不含可转债、不含股票 ETF 主样本）。须含足量**科创板**成交日，否则科创门槛差分不可检。
- **排除（默认）**：调仓日未上市；退市整理期交易日（见实验 H；纳入须单独标签）；信号日或成交日停牌/全日无成交（失败，规则同 D 的 skip）；数据缺失无法识别板块或无法换算股数。
- **股票池 PIT**：每个调仓日只用当日已生效可交易名单（勿用核对日还上市的全 A；指数成分按调样生效日——可与实验 C 共用）。
- **区间建议**：待数据接入后锁定起止。建议复现默认（可改，须写入配置）：
  - 主窗：最近完整 5 个自然年交易日（须覆盖科创板开市后）；
  - 稳健：创业板/科创板分段；小名义 vs 中名义分档。
- **PIT 切片原则**：整手门槛、科创单笔上下限、板块归属，一律按成交日当时规则（两所交易规则修订切日若影响数量条款，须按当时文本，不得用核对日规则铺满）。

### 3.1 oos_split 占位（拉数前冻结；禁 holdout 反调）

配置占位字段（数值待锁，先占位）：

- `oos_split.is_start` / `oos_split.is_end`：样本内（IS）起止交易日  
- `oos_split.holdout_start` / `oos_split.holdout_end`：样本外 / holdout 起止  

**硬规则**：holdout / OOS 段**只用于一次性报告**；**禁止**用 holdout 反调规则、撮合参数、显著性阈值或任何事后标定。切分一经写入 params 即冻结，不得因 IS 结果改 holdout 边界。

## 4. 标签 / 对照设计

### 4.1 对照

见 §2.2 三组。主对比：

1. **E1 − E0**：诚实整手相对任意股数的仓位/换手/废单差；  
2. **E2 − E1**：创业板误套 200 起带来的额外废单与仓位偏离（应集中在创业板，而非科创）。

### 4.2 成功 / 失败判据（相对）

主指标：

1. 年化收益差 ΔAnn、最大回撤差 ΔMDD（E1−E0、E2−E1）；  
2. 废单/跳过笔数、实际成交股数 vs 意图股数、计划换手 vs 实际换手、期末残余仓与「碎片仓」只数；  
3. 科创板子集 vs 主板/创业板；小名义档 vs 中名义档是否更大。

**相对判据（草稿）**：若废单率差 **≥ R** 或实际换手下降 **≥ X** 或 |ΔAnn| **≥ Y**（E1−E0），记「整手鸿沟显著」；若 E2 相对 E1 在创业板子集废单差 **≥ R2**，记「创业板误套 200 显著有害」。

**R / X / Y / R2（拉数前写入 params；禁 holdout 标定）**

| 符号 | 含义（占位） | 规则 |
|------|--------------|------|
| R | E1 相对 E0 废单/跳过率差门槛 | 拉数前写入 `params.R` 并冻结 |
| X | 实际换手下降门槛 | 拉数前写入 `params.X` 并冻结 |
| Y | abs(ΔAnn(E1−E0)) 显著门槛 | 拉数前写入 `params.Y` 并冻结 |
| R2 | E2−E1 创业板废单差门槛 | 拉数前写入 `params.R2` 并冻结 |

阈值可在 **IS 标定窗**（非 holdout）内事先约定噪声带后写入；**禁止用 holdout / OOS 段标定或反调**。本页可不填死数，但开工拉数前必须落进 params。

**失败/不显著**：差落在标定噪声带内，或仅由个别低价碎股日驱动——结论栏写明，不得改口称「整手无关」。

结论栏：空。跑完只写「该假设下差多少」，不写「所以该买这类票」。

### 4.3 数值红线 v0 豁免（本机制实验）

本实验**只验整手 / 科创 200 / 零股一次性卖**这一执行鸿沟机制，**不为组合策略放行实盘**。

- **显式豁免**：数值红线 v0（如单票仓位上限约 15%、行业集中约 30%、回撤熔断等组合约束）**对本实验纸面/干跑豁免**——不因净值/IC/仓位红线否决本机制对照；小账户高换手信号仍允许只比 E0/E1/E2。  
- **不豁免**：回测诚信对照（未复权成交价、写死开/收、停牌/无量失败、T+1、整手按当时板块、禁 holdout 反调、禁荐股/禁当实盘预期）一律照做。  
- **不得沿用**：本豁免**不得**被组合策略或其他假设页拿去绕开红线 v0。

## 5. 预期失效条件

本假设或实验设定在下列情形下失效/须重切，不得硬套：

1. **创业板误写成 200 起**却当诚实组主结论（E2 仅作反例，不得与 E1 混报）。  
2. **零股拆多笔卖**：送转/红利后余额不足一手被拆成多笔「卖出成功」。  
3. **科创上限未切**：限价/市价单笔超过当时上限仍全成，或不声明拆单规则。  
4. **标的错位**：用股票 100 股套 ETF，或用可转债面额整手套本页。  
5. **盘后数量条款混进竞价默认**：把科创盘后 200～100 万默认并进连续竞价撮合（本页默认关盘后）。  
6. **与 A/D 混报主结论**：把涨停一字或开/收时点差分算进「整手差」却不声明。  
7. **宇宙泄露**：用今天还上市的票或今天的指数成分回放；科创样本过少却宣称科创门槛无影响。  
8. **T+1 关闭**或成交时点未在三组间对齐。  
9. **规则切日未切片**：用核对日数量条款铺满历史。
