# 清单与配方

> 领域：金融股票。增量追加。不荐股；只作观察与复盘骨架。

## 2026-09-18 中短线观察清单（人性版）

看盘前问自己：

1. **情绪在哪一段？** 启动 / 高潮 / 退潮 / 冰点（不要用愿望代替判断）
2. **是否已经太一致？** 人人都在说同一热点 → 警惕拥挤
3. **龙头还是跟风？** 优先看辨识度最高的那只的态度，跟风更脆
4. **有没有拥挤迹象？** 抱团、同涨同跌、成交过度集中
5. **退潮了吗？** 高位股集中砸、核按钮式下跌 → 少做、等冰点，不急着抄
6. **钱在不在跷跷板切换？** 科技退 ↔ 题材起，别拿旧主线的惯性硬扛

## 2026-09-19 量化打基础 · 喂养清单

每轮金融日至少从下面挑 **2～4 条**写进 `事实与坑`（要可复用，拒绝水文）：

1. **数据坑**：复权差错、未来函数、停牌/一字板怎么处理  
2. **标签与收益**：持有期、开收盘价、涨跌停不可成交怎么建模  
3. **因子卫生**：标准化、去极值、行业/市值中性、样本外  
4. **拥挤与失效**：同质化因子、拥挤度代理指标、失效怎么观测  
5. **回测诚信**：过拟合症状、换手与成本、分段稳健性  
6. **从笔记到实验**：一条结论怎样写成「可复现实验条目」（输入/假设/检验/结论）

手盘观察清单（上一节）保留作**情绪/结构输入**；量化阶段把它翻译成可编码概念，不翻译成荐股。

## 2026-09-19 一人机构量化 · 五环骨架（自有资金）

目标形态：策略研发 → 历史回测 → 模拟验证 → 程序化实盘 → 风控+复盘迭代。

| 环 | 本阶段先囤什么（进智库） | 以后落地工具（暂不荐股） |
|----|--------------------------|---------------------------|
| 研发 | 因子/假设/可复现实验条目 | Cursor + 智库 |
| 回测 | 数据口径、成本、未来函数坑 | 聚宽/掘金/米筐/Backtrader 等 |
| 仿真 | 实盘-回测鸿沟清单 | 券商模拟/仿真 |
| 实盘 | 程序化报备、权限、日频/分钟级边界 | QMT/PTrade 等券商通道 |
| 风控 | 仓位/回撤/单票集中度写成规则条目 | 写进策略代码硬约束 |

当前优先做 **阶段 0**：把「自己的学习型 AI」养稳（口径可纠、知识可见、跨会话仍在）。五环表是阶段 1+ 地图，**不抢跑去催开户/写实盘**。
## 2026-09-21 回测开跑前检查（硬约束）
写任何收益曲线前先过一遍（不通过 = 实验作废）：
1. **T+1**：股票买入后下一交易日才允许卖？有没有误开 T+0？
2. **涨跌停**：是否按**交易日 × 板块 × 是否风险警示**取当时限制？主板 ST 是否在 2026-07-06 处分段（前 5%、后 10%）？
3. **价格口径**：收益用复权；涨跌停/停牌/一字板用**不复权**（除权日用交易所前收盘=除权参考价）。
4. **成交**：涨停买入、跌停卖出是否允许记成 100% 成交？保护限 102%/98% 有没有当成「市价一定吃得到」？
5. **成本**：印花税是否只在卖出、并在 2023-08-28 前后切换 1‰ / 0.5‰？佣金+滑点是否 > 0？
6. **可见信息**：财务/估值因子是否按**披露日**对齐，而不是报告期末？
## 2026-09-21 可复现实验条目（先记骨架，以后有代码再跑）
### 实验 A：涨停可成交性（执行鸿沟）
- **输入**：同一选股规则、同一持有期；价格用不复权；涨跌停按「当时规则」。
- **假设**：把「涨停仍按收盘价买到 / 跌停仍按收盘价卖掉」改成「触及涨停的买入、触及跌停的卖出记未成交」，收益会明显下降；高换手、爱追涨的规则下降更大。
- **检验**：A0 = 默认收盘全成交；A1 = 涨停买/跌停卖记失败（持仓顺延或空仓，需事先写死规则）。对比年化、回撤、换手，分段看主板 10% vs 创业板/科创板 20%。
- **结论栏**：跑完再填。未跑之前禁止把 A0 当实盘预期。
### 实验 B：印花税时点 + T+1（回测诚信）
- **输入**：同一因子、同一换手假设。
- **假设**：B0 零成本 + 可 T+0；B1 股票 T+1 + 卖出印花税按 2023-08-28 分段（前 1‰、后 0.5‰）+ 非零佣金/滑点。B0 会系统性高估，尤其高频换手。
- **检验**：两条净值并排；单独报告「成本吃掉的那截」和「因 T+1 卖不出而少做的那截」。
- **结论栏**：跑完再填。B0 只允许当对照，不允许当策略成绩。
