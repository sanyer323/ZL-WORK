## 1. 一句话假设（可检验、可证伪）

同一选股规则、同一持有期、同一 T+1 下，把隔夜信号的成交从「次日开盘价（停牌/全日无成交记失败）」换成「次日收盘价（停牌/无成交亦失败）」会系统抹掉开盘跳空贡献；若再换成「含停牌日在内一律按收盘价成交」（停牌日收盘=前收盘当横盘），还会把不可交易日当成可交易，**净值、失败笔数与隔夜跳空归因会显著偏离诚实开盘组**。高换手、隔夜跳空大的规则偏离更大。

证伪方向：若 D1（次日收）相对 D0（次日开）的收益差/跳空贡献差在标定噪声带内可忽略，且 D2（天真含停牌）相对诚实组的失败笔数与净值差亦不显著，则本假设在该样本与撮合设定下不成立。

## 2. 可编码概念 / 定义

### 2.1 成交时点（写死；本实验主测对象）

- 信号在调仓日 `d` **收盘后**可见；默认成交日 = **次一交易日 `d+1`**（与口径「成交时点写死」一致）。
- **开盘价**：交易所定义的当日竞价第一笔成交价（先开盘集合竞价，走不成再连续竞价）；日频字段用数据商 `open`，须注明是否等于集合竞价成交价。
- **收盘价**：收盘集合竞价产生的收盘价（产生不了则按交易所「最后一分钟加权」等当时规则）；**当日无成交时，行情收盘价常等于前收盘——这不是可成交价**。
- **禁止**：用复权开盘/复权收盘当成交价；同一报告混用开/收却只报一条净值；把盘后固定价格默认并进「收盘一定成交」（盘后另案，见实验 M；本页默认关闭）。

### 2.2 停牌 / 全日无成交标签

```
# 伪代码级；不编造历史真数
is_no_trade(i, t) = (volume == 0) or (amount == 0) or is_suspended(i, t)
# 行情坑：无成交日 close 可能被填成 pre_close，涨跌幅显示为 0
# → is_no_trade 必须用停牌旗或量能，禁止用「涨跌幅==0」反推可交易

tradable(i, t) = listed_and_not_in_exit_only_if_excluded
                 and (not is_no_trade(i, t))
                 # 本页最小集：无量/停牌 = 不可交易
```

- **fail_policy（写死默认）**：本实验配置默认 **`fail_policy=skip`**（停牌/全日无成交等失败时跳过该腿、不成交、不顺延）；与 A 假跑对齐。允许在拉数前改配置为 `defer`（顺延下一可交易日再试），但**必须写入 params 并冻结**；**禁止跑后/看完净值再改口**。未写明则以 skip 为准。

### 2.3 三组撮合（本实验编码）

| 组 | 成交价 | 停牌 / 全日无成交 |
|----|--------|-------------------|
| D0 诚实-次日开 | `d+1` 开盘价 | 记失败（成交量 0） |
| D1 诚实-次日收 | `d+1` 收盘价 | 记失败（成交量 0） |
| D2 天真-含停牌 | 一律按「收盘价」 | **仍成交**（把无量日 close=pre_close 当横盘） |

同一信号、同一 T+1、同一成本开关（本页可先零成本只比时点与停牌差；成本见清单早期 B / 实验 S/T，涨停板上约束见假设 A——**勿把 A 的板上硬约束混进 D 主结论**；若引擎已实现 A1，可作稳健性叠加并在报告声明）。

整手约束本页不主测（见实验 E）；若引擎已实现，三组应同开同关。

## 3. 样本区间

- **宇宙（默认）**：沪深 A 股股票（不含可转债、不含股票 ETF 主样本）。
- **排除（默认）**：调仓日未上市；退市整理期交易日（另见实验 H；纳入须单独标签）；信号日或成交日数据缺失无法取 `open`/`close`/停牌旗；无开盘价定义日（若数据商空 open）记失败或剔除，须事先写死。
- **股票池 PIT**：每个调仓日只用当日已生效可交易名单（勿用核对日还上市的全 A；指数成分按调样生效日——与实验 C 一致，本页可复用其名单表）。
- **区间建议**：待数据接入后锁定起止。建议复现默认（可改，须写入配置）：
  - 主窗：最近完整 5 个自然年交易日；
  - 稳健：含至少一段高波动/密集停牌子窗（若样本够），以及沪市收盘价产生方式切日（2018-08-20）前后若落入样本须按当时规则取收盘价，不得用现行定义铺满。
- **PIT 切片原则**：开盘/收盘价产生方式、停牌定义、T+1，一律按成交日当时规则。


### 3.1 oos_split 占位（拉数前冻结；禁 holdout 反调）

配置占位字段（数值待锁，先占位）：

## 4. 标签 / 对照设计

### 4.1 对照

见 §2.3 三组。主对比：

1. **D1 − D0**：纯成交时点差（开→收抹掉的隔夜跳空）；  
2. **D2 − D0**（及 D2 − D1）：停牌假成交带来的虚增可交易日与净值偏差。

### 4.2 隔夜跳空归因（须报）

对每笔成功成交（D0 与 D1 均成功的交集）：

```
gap_ret = open(d+1) / close(d) - 1     # 隔夜跳空（未复权价比价仅作归因；组合收益仍按约定复权收益列）
intraday_ret = close(d+1) / open(d+1) - 1
```

报告：D0 实际捕获的 gap 贡献 vs D1（按收成交通常把 gap 并进「持有到收盘」路径）的差异；停牌失败日不计入 gap 均值（单独计失败笔数）。

### 4.3 成功 / 失败判据（相对）

主指标：

1. 年化收益差 ΔAnn、最大回撤差 ΔMDD（D1−D0、D2−D0）；  
2. 失败笔数（停牌/无量）、计划换手 vs 实际换手、期末残余仓；  
3. 隔夜跳空贡献差（D0 路径 vs D1 路径）；高换手子集是否更大。

**相对判据（草稿）**：若 |ΔAnn(D1−D0)| **≥ Y** 或跳空贡献差 **≥ G**，记「开/收时点显著」；若 D2 相对诚实组失败笔数差 **≥ N** 或 |ΔAnn| **≥ Y2**，记「停牌假成交显著吹胖」。

**Y / G / N / Y2（拉数前写入 params；禁 holdout 标定）**

| 符号 | 含义（占位） | 规则 |
|------|--------------|------|
| Y | abs(ΔAnn(D1−D0)) 显著门槛 | 拉数前写入 `params.Y` 并冻结 |
| G | 隔夜跳空贡献差显著门槛 | 拉数前写入 `params.G` 并冻结 |
| N | D2 相对诚实组失败笔数差门槛 | 拉数前写入 `params.N` 并冻结 |
| Y2 | D2 相对诚实组 abs(ΔAnn) 显著门槛 | 拉数前写入 `params.Y2` 并冻结 |

四阈值可在 **IS 标定窗**（非 holdout）内事先约定噪声带后写入；**禁止用 holdout / OOS 段标定或反调**这些阈值。本页可不填死数，但开工拉数前必须落进 params。

**失败/不显著**：差落在标定噪声带内，或仅由个别极端停牌日驱动——结论栏写明，不得改口称「时点无关」。

结论栏：空。跑完只写「该假设下差多少」，不写「所以该买这类票」。

### 4.4 数值红线 v0 豁免（本机制实验）

本实验**只验成交时点（开 vs 收）与停牌假成交**这一执行鸿沟机制，**不为组合策略放行实盘**。

- **显式豁免**：数值红线 v0（如单票仓位上限约 15%、行业集中约 30%、回撤熔断等组合约束）**对本实验纸面/干跑豁免**——不因净值/IC/仓位红线否决本机制对照；信号即便呈高集中轮动，仍允许只比 D0/D1/D2 时点与停牌差。  
- **不豁免**：回测诚信对照（未复权成交价、写死开/收、停牌/无量失败、T+1、禁 holdout 反调、禁荐股/禁当实盘预期）一律照做。  
- **不得沿用**：本豁免**不得**被组合策略或其他假设页拿去绕开红线 v0。

## 5. 预期失效条件

本假设或实验设定在下列情形下失效/须重切，不得硬套：

1. **成交时点未写死**：同一报告混用次日开与次日收，或未声明就报一条净值。  
2. **复权成交价**：用复权开/收当撮合价。  
3. **停牌假成交未标**：用「涨跌幅=0」或 close==pre_close 当可交易横盘，而不用停牌旗/成交量。  
4. **盘后当收盘无限量**：把盘后固定价格默认并进「次日收盘一定成」（本页默认关；单列须按板块落地日切片）。  
5. **收盘价定义漂移**：沪市股票收盘集合竞价切日前后用同一产生方式铺满；或把基金尾盘规则套进股票。  
6. **与假设 A 混报主结论**：把涨停一字/封板硬约束的差分算进「开/收时点差」却不声明。  
7. **宇宙泄露**：用今天还上市的票或今天的指数成分回放。  
8. **标的错位**：可转债当日回转或股票 ETF 规则套进本股票实验。  
9. **T+1 关闭**：股票实验关掉 T+1，虚增当日回转（本页要求同一 T+1）。
