## 1. 一句话假设（可检验、可证伪）

同一风险警示相关股票宇宙、同一未复权价、同一 T+1 下，把「主板风险警示股当日累计买入（竞价+大宗+盘后）上限 **50 万股**」整段忽略（或只计竞价不累计大宗/盘后），或把该上限误套到**退市整理股 / 科创板风险警示**，相对「仅对**沪深主板风险警示股**累计买入封顶 50 万股；整理股不套；科创板不进风险警示板 → 本页不套；超限买入腿记失败/截断」的 PIT 诚实组，会**系统性高估可买入名义与换手、或在整理/科创桶发明假废单**；差异应**集中在「忽略上限 / 误套整理 / 误套科创 / 累计通道不全」桶**，而不是随机散开。

证伪方向：若天真组 / 误套组相对诚实组的买入失败率差、可买名义差、腿净值差在标定噪声带内可忽略，且分桶不改变结论（差异不集中在 50 万上限相关桶），则本假设在该样本与执行设定下不成立。

### 4.3 数值红线 v0 豁免（本机制实验）

本实验**只验风险警示买入上限执行诚信**，**不为交易策略放行实盘**。

- **显式豁免**：数值红线 v0 中单票仓位、行业集中、回撤熔断等组合约束（**`params.redline_v0_exempt_scope=position_industry_dd_only`**）**对本实验纸面/干跑豁免**。  
- **不豁免**：回测诚信（PIT 适用范围、禁 holdout 反调、禁荐股/禁当实盘预期）一律照做。  
- **不得沿用**：本豁免**不得**被组合策略或其他假设页拿去绕开红线 v0。

## 5. 预期失效条件

本假设或实验设定在下列情形下失效/须重切，不得硬套：

1. **用复权价**。  
2. **把 H 整理主测、X 主板 ST 涨跌幅、A 板上可成交、E 整手重开混进本页主结论**。  
3. **把退市整理股或科创板写成 AD2 诚实必套 50 万**（与事实与坑 / H 旁路冲突）。  
4. **累计通道只计竞价却声称验了「竞价+大宗+盘后」**。  
5. **缺风险警示日旗却静默当非 ST / 或静默套上限**。  
6. **宇宙泄露 / holdout 反调**：看完 OOS 再改 `ad0_primary_demo` 或 **`params.Y` 等门槛**。
