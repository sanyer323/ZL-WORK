# 清单与配方

> 领域：视频制作。增量追加，勿整篇清空。条目建议带日期。

## 2026-09-23 开片前先定版本

缺一项就停，不要先渲：

1. **原理还是排故？** 选一个脚本（`旁白文案_原理讲解版.txt` 或 `旁白文案_工程师培训版.txt`），不要混用片尾句。
2. **数字跟哪本手册？** 默认 FY301ME（电压↑ → 先导压↑）；出现 fycalme 必须写来源和极性。
3. **成片给谁看？** 自己复看 / 内部培训 / 外发上传——编码和响度要求不同。
4. **字幕策略**：默认产出独立 UTF-8 SRT + 一份软字幕成片；烧录只在对方播放器不会挂字幕轨时再做。

## 2026-09-23 成片检查（对内仿真片）

1. 分辨率和画幅跟源一致（现成脚本 1280×720）；不要临时拉成 1080p/4K 却不重渲字号。
2. 帧率跟源一致（现成脚本 **20 fps**）；concat 前各段同一 FPS。
3. 视频：H.264、`yuv420p`、逐行、恒定帧率。SDR，按 BT.709 理解，不打 HDR。
4. 音频：AAC、48 kHz 更稳；对内 128k 可以，外发立体声再往上加。
5. 真峰值不要顶到 0 dBFS（SAPI 混音后听一遍峰值）。
6. SRT：纯 UTF-8、无样式、时间轴和旁白一致；和成片一起归档。
7. MP4 需要网页秒开时加 Fast Start（`moov` 在文件头）。

## 2026-09-23 外发上传（YouTube）另加这几项

内部片不必条条照做；**真要上传**再勾：

1. 容器 MP4，无 Edit Lists，Fast Start。
2. Closed GOP，GOP ≈ 帧率一半；VBR；参考 1080p 常帧率 8 Mbps。
3. 音频 48 kHz；立体声按官方参考 384 kbps。
4. 另传一份 plain UTF-8 SRT（不要只靠烧录）。
5. 仍不要把社区「−14 LUFS」写成官方验收。

## 入库纪律

- 只写会改变下次分镜、编码、字幕、响度决策的条目。
- 平台算法、涨粉技巧、一次性新闻不进。
- 短规矩进 `positioner-rd`；不新建空的 `fy301-simulation-video` Skill，也不把 ffmpeg 手册塞进去。
