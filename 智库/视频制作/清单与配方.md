# 清单与配方

> 领域：视频制作。增量追加，勿整篇清空。条目建议带日期。

## 2026-09-27 成片出门前

1. **这版讲什么？** 原理 或 排故，二选一；不要混剪。
2. **源参数锁住了吗？** 帧率跟脚本（本仓库 20 fps）；分辨率跟素材（常见 1280×720 就按 720p 出，不硬拉）。
3. **容器对不对？** MP4 + H.264 + AAC；Closed GOP；Fast Start（`moov` 在前）；无 Edit Lists；SDR 标 BT.709。
4. **码率只当参考：** 720p SDR 常帧率约 5 Mbps，1080p 约 8 Mbps（YouTube 官方表）。B 站只守峰值 ≤ 60 Mbps 等上限。
5. **字幕：** 另挂 UTF-8 `.srt`（无样式）；网页播放另出 `.vtt`。默认可关软字幕。对照旁白念一遍，漏句就不过。
6. **响度：** 用 BS.1770 量一遍。若按广播交：约 −23 LUFS、真峰值 ≤ −1 dBTP。不要写没有官方页的平台靶。
7. **片头：** 5 秒内点题（细则在编剧罐）。
