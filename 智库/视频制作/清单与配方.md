## 2026-09-20 开剪 / 成片前先过这 7 项

缺一项就停，不要先渲 5 段仿真再改口吻：

1. **这一版是原理还是排故？** 原理用「本段要点（机理）」；排故用「现场结论」。两套旁白分文件。
2. **极性锁死没有？** 电压–先导压按 FY301ME；出现 fycalme 必须同屏写来源。
3. **每段三件套齐了吗？** 画面证据（能看见的状态变化）+ 旁白（只补因果）+ 一句要点。
4. **出处在哪本手册？** 旁白里的数（30–70 V、FYCAL@20 psi、3.8 mA、Hall 2–4 mm）对得上 FY301ME，不靠记忆。
5. **成片双文件：** `mp4` + 独立 UTF-8 `.srt`；需要能关字幕时不要只交烧录版。
6. **编码守官方公约数：** MP4 / H.264 / AAC / 16:9 / 帧率跟源；1080p 常帧率参考 8 Mbps（YouTube Help，核对日 2026-09-20）。
7. **字幕不挡机理：** 曲线、判据数字、零件标签留在画面中部，字幕靠下。

## 2026-09-23 成片检查（对内仿真片）
1. 分辨率和画幅跟源一致（现成脚本 1280×720）；不要临时拉成 1080p/4K 却不重渲字号。
2. 帧率跟源一致（现成脚本 **20 fps**）；concat 前各段同一 FPS。
3. 视频：H.264、`yuv420p`、逐行、恒定帧率。SDR，按 BT.709 理解，不打 HDR。
4. 音频：AAC、48 kHz 更稳；对内 128k 可以，外发立体声再往上加。
5. 真峰值不要顶到 0 dBFS（SAPI 混音后听一遍峰值）。
6. SRT：纯 UTF-8、无样式、时间轴和旁白一致；和成片一起归档。
7. MP4 需要网页秒开时加 Fast Start（`moov` 在文件头）。

## 2026-09-27 成片出门前
1. **这版讲什么？** 原理 或 排故，二选一；不要混剪。
2. **源参数锁住了吗？** 帧率跟脚本（本仓库 20 fps）；分辨率跟素材（常见 1280×720 就按 720p 出，不硬拉）。
3. **容器对不对？** MP4 + H.264 + AAC；Closed GOP；Fast Start（`moov` 在前）；无 Edit Lists；SDR 标 BT.709。
4. **码率只当参考：** 720p SDR 常帧率约 5 Mbps，1080p 约 8 Mbps（YouTube 官方表）。B 站只守峰值 ≤ 60 Mbps 等上限。
5. **字幕：** 另挂 UTF-8 `.srt`（无样式）；网页播放另出 `.vtt`。默认可关软字幕。对照旁白念一遍，漏句就不过。
6. **响度：** 用 BS.1770 量一遍。若按广播交：约 −23 LUFS、真峰值 ≤ −1 dBTP。不要写没有官方页的平台靶。
7. **片头：** 5 秒内点题（细则在编剧罐）。

## 2026-09-30 对内成片（仿真讲解）
在 09-27 出门清单上只加这几项，缺了再渲：
1. **旁白采样率锁住了吗？** 对内拼接可以继续 16 kHz 单声道（现成脚本如此）。**外发前**重采样到 48 kHz 再编码 AAC。
2. **concat 前同一套流。** 采样率、声道、编码器不一致不要 `-c copy`。
3. **外发 GOP：** 20 fps → Closed GOP **10 帧**；High Profile；`-movflags +faststart`；不要 Edit Lists。
4. **响度先量再决定套哪套靶。** 命令形态：`ffmpeg -nostats -i 成片.mp4 -filter:a ebur128=peak=true -f null -`，看摘要里的 `I` 和真峰值。对内：真峰值留余量即可。交中国数字电视：约 −24 LKFS、真峰值 ≤ −2 dBTP。交欧广电：−23 LUFS、≤ −1 dBTP。不要用 `loudnorm` 默认值冒充 R128。
5. 仍不要把社区「YouTube −14 LUFS」写成官方验收。
- 只写会改变下次导出/混音/上传决定的条目。
- ffmpeg 手册和分镜全文留在 `AI研发产品/研发仿真视频/`，不搬进 Skill。

## 2026-10-07 外发上传（YouTube）字幕 / 色域 / 披露
内部片不必做；**真要上传**再勾。接在 10-04 章节清单后面：
1. **视频语言**设成片里实际说的语言（本仓库中文旁白 → 中文）。自动字幕只跟 default language。
2. Studio → Subtitles → ADD LANGUAGE → Upload file → **With timing**，上传仓库那份 UTF-8 `.srt`。不要选 Auto-sync 把旁白 txt 丢进去。
3. 自动字幕若自己上线：对照 SRT 看术语（FYCAL / Hall / 先导压）。不对就删自动轨，只留上传轨。
4. **色域：** `ffprobe` 看 `color_primaries` / `color_trc` / `color_space` / `color_range`。外发标 BT.709，范围 **tv（limited）**。matplotlib 全范围先转再标，不要只改标签。不要 RGB matrix，不要 HDR。
5. 编码命令形态只补标签时：`-color_primaries bt709 -color_trc bt709 -colorspace bt709 -color_range tv`（像素已是 limited yuv420p 才这么干）。像素还是全范围时，用 ffmpeg `colorspace=all=bt709:range=tv:format=yuv420p` 再编码。
