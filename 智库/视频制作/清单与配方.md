# 清单与配方

> 领域：视频制作。增量追加，勿整篇清空。条目建议带日期。

## 2026-09-20 开剪 / 成片前先过这 7 项

缺一项就停，不要先渲 5 段仿真再改口吻：

1. **这一版是原理还是排故？** 原理用「本段要点（机理）」；排故用「现场结论」。两套旁白分文件。
2. **极性锁死没有？** 电压–先导压按 FY301ME；出现 fycalme 必须同屏写来源。
3. **每段三件套齐了吗？** 画面证据（能看见的状态变化）+ 旁白（只补因果）+ 一句要点。
4. **出处在哪本手册？** 旁白里的数（30–70 V、FYCAL@20 psi、3.8 mA、Hall 2–4 mm）对得上 FY301ME，不靠记忆。
5. **成片双文件：** `mp4` + 独立 UTF-8 `.srt`；需要能关字幕时不要只交烧录版。
6. **编码守官方公约数：** MP4 / H.264 / AAC / 16:9 / 帧率跟源；1080p 常帧率参考 8 Mbps（YouTube Help，核对日 2026-09-20）。
7. **字幕不挡机理：** 曲线、判据数字、零件标签留在画面中部，字幕靠下。

## 入库纪律

- 只写会改变下次分镜、成片或上传选择的条目；平台周更活动、一次性调参不进。
- 没有官方页可核对的平台码率，宁缺勿写。
- 短规矩进 `positioner-rd`；ffmpeg 命令和分镜全文留在 `AI研发产品/研发仿真视频/`，不整篇搬进 Skill。
