# 事实与坑

> 领域：视频制作。增量追加，勿整篇清空。条目建议带日期。

## 2026-09-27 首轮（成片编码 + 字幕 + 响度）

### 研发仿真 ≠ 营销片
- 本仓库 `AI研发产品/研发仿真视频/README.md` 写明：面向研发的可计算仿真，不是营销三维宣传片。
- **坑**：用卖货五段式或炫光片头套研发讲解，机理被冲掉，现场对不上手册。

### YouTube 官方上传承包，本仓库跟源帧率
- YouTube Help《recommended upload encoding settings》（核对日 2026-09-27，`support.google.com/youtube/answer/1722171`）：容器 **MP4**；**无 Edit Lists**（否则可能处理失败）；**moov 在文件头（Fast Start）**；视频 **H.264**（逐行、High Profile、连续 2 个 B 帧、**Closed GOP** 且 GOP≈半帧率、CABAC、4:2:0）；音频 **AAC-LC / Opus / Eclipsa**，**48 kHz**，立体声参考 **384 kbps**。
- SDR 参考码率（常帧率 24/25/30）：720p **5 Mbps**，1080p **8 Mbps**。高帧率（48/50/60）对应 7.5 / 12 Mbps。SDR 色域官方写 **BT.709**。
- 帧率：**按录制/生成源上传**。官方列举常见 24/25/30/48/50/60，并写明 **其它帧率也可接受**。本仓库 `render_sims.py` / `render_product_parts.py` 是 **20 fps** → 保持 20，不升 30。
- **坑**：隔行未去隔行再传；为「更像网播」改帧率导致动作时基漂。

### 字幕：软字幕优先，SRT 只要纯 UTF-8
- YouTube Help《Supported subtitle and closed caption files》（核对日 2026-09-27，`support.google.com/youtube/answer/2734698`）：新手推荐 **SubRip `.srt`**；**只认基础版，样式标记不生效**；必须 **plain UTF-8**。
- W3C WebVTT（CRD 2026-05-20，`www.w3.org/TR/2026/CRD-webvtt1-20260520/`）：网页播放器用 `.vtt`，文件体必须 **UTF-8**，首行 `WEBVTT`，毫秒用 **点** 不是逗号。仓库现成片是 `.srt`，上传/网页各跟各的格式，不要改后缀冒充。
- WCAG 2.2 SC **1.2.2 Captions (Prerecorded)**（Level A，`www.w3.org/TR/WCAG22/`）：预录同步媒体要有字幕，除非该媒体本身被明确标成「文本的替代」。
- 本仓库已有烧录版与软字幕版。默认出 **可开关软字幕**；烧录只作不能挂轨的场合。
- **坑**：用 GBK 存中文 SRT；把 ASS 花字当 YouTube 字幕；只烧录、观众关不掉。

### 响度：BS.1770 是尺子，R128 是广播靶，不要编平台靶
- **怎么量**：ITU-R **BS.1770-5**（2023-11，ITU 官方 PDF）定义响度与真峰值算法（LUFS / dBTP）。它不规定你该响到多少。
- **广播靶**：EBU **R 128**（官方 PDF `tech.ebu.ch`）在这把尺子上取 **节目响度 −23.0 LUFS**、真峰值不超过 **−1 dBTP**。
- YouTube 帮助页**没有**公布「上传必须 −14 LUFS」。没有官方页就不写。
- **坑**：拿峰值表当响度；把博客里的「油管 −14」写进交付清单。

### B 站只记官方上限，不记推荐码率
- 哔哩哔哩开放平台投稿技术限制（核对日 2026-09-27，开放平台文档摘要）：单文件 **4 GB**、时长 **< 5 小时**、封装推荐 **MP4 / MOV / MKV**、**峰值码率 ≤ 60 Mbps**、分辨率最大 **4096×2160**、帧率最大 **120 fps**、**GOP 不超过 10 秒**、建议逐行。
- 第三方「1080p 建议 6 Mbps」对不上官方页，**不入库**。
- **坑**：把博主码率表抄成「B 站官方推荐」。
