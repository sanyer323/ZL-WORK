# 清单与配方

> 领域：工业产品-定位器。增量追加，勿整篇清空。条目建议带日期。

## 2026-09-19 询价/选型先问这 8 项

动手画型号或写方案前，缺一项就停：

1. **直行程还是角行程？** 安装接口不是同一本（直：IEC 60534-6-1 / GB/T 17213.6；角：IEC 60534-6-2）。
2. **单作用还是双作用？** 气路出口数、故障位（失气开/关/保位）跟着变。
3. **行程/转角是否落在标准安装范围内？** 直行程标准化接口一般只覆盖侧面安装、约 10～100 mm。
4. **气源**：供气压力；现场有没有过滤减压；露点/油/颗粒有没有人管。
5. **信号**：纯 4–20 mA，还是 4–20 mA + HART；要不要阀位回讯。
6. **防爆/防护**：证书体系（国标/IECEx/ATEX）和安装区，不要只抄「隔爆」两个字。
7. **诊断要到哪一层**：只要能跑，还是要 NE107 四态进 DCS。
8. **验收对哪本标准**：阀用 4213；定位器性能用 22137；支架用 17213.6 / 60534-6。写进合同再开工。

## 2026-09-19 现场「不动」先查气，再查电

1. 过滤器是否积水/积油；减压阀设定是否在手册供气范围。
2. 喷嘴/节流孔是否堵（先导级脏，症状像控制坏了）。
3. 反馈连杆/支架是否松、是否按侧面标准安装乱改。
4. 回路电流是否真的在 4–20 mA（HART 手操器能通 ≠ 模拟给定对）。
5. FY301：阀到位后读压电电压；默认按 FY301ME 解释趋势。
